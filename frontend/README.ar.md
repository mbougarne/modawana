# الواجهة الأمامية (Frontend)

[English](README.md) · [المشروع](../README.ar.md)

تعتمد صفحات القراءة العامة ولوحة تحكم المالك الخاصة على React وTypeScript وWebpack. يُستورد الكود المصدري المشترك من المجلد الجذري `ui/src` عبر المسار المستعار `@ui`، باستخدام بيئة تشغيل موحدة لـ React وملف قفل npm واحد (`package-lock.json`). وتتشارك اللغات الثلاث (العربية باتجاه RTL، والإنجليزية، والفرنسية) المكونات البرمجية نفسها.

شغّل الأمر `node scripts/project.mjs dev` من المجلد الجذري لتشغيل خادمي التطوير الخاصين بـ Go وWebpack معاً. راجع دليل [الإعداد المحلي](../docs/getting-started.ar.md). تحتوي حزم بناء الإنتاج على أصول تحمل بصمات تجزئة رقمية (content hashing) وبيان للأصول (manifest)، ويقوم خادم Go بتقديمها مباشرة من أصل النطاق (origin) نفسه الذي يخدم واجهة البرمجة (API).

```sh
npm --prefix frontend run check
node scripts/project.mjs build
```

تتولى هذه الفحوصات تدقيق سلامة الأنواع في TypeScript للتطبيق ومكونات الواجهة المشتركة، فضلاً عن تشغيل اختبارات شجرة DOM وعقود السلوك. ويوضح دليل [المساهمة](../CONTRIBUTING.ar.md) أدوات فحص المتصفح التشخيصية الاختيارية وحدودها. يُرجى الاطلاع على وثائق [التصميم](../docs/design.ar.md)، و[عقود الواجهة](../docs/ui-contracts.ar.md)، و[الصفحات العامة](../docs/public-pages.ar.md)، و[أدوات المالك](../docs/owner-tools.ar.md). احذر تماماً من تضمين أسرار التشغيل في أصول المتصفح، ولا تعتمد أبداً على إخفاء عناصر الواجهة كبديل عن التحقق البرمجي من الصلاحيات والتفويض.

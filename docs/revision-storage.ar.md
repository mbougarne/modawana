# تخزين المراجعات الثابتة

[English](revision-storage.md)

يقدم التطبيق [واجهة المحتوى](api/content.ar.md)
بحد 1 MiB لجسم Markdown وعمليات تدعم إعادة المحاولة دون تكرار.
تكتب `content.Revisions.Save` جسم Markdown كاملاً بصيغة UTF-8 بحد 2 MiB، مع
نسخة جديدة حتى عند تعديل البيانات الوصفية فقط، ثم تقارن النسخة المتوقعة وتعتمد
بيانات SQLite ومؤشر المسودة. يبقى مؤشر النشر دون تغيير. تنشئ النسخة المتوقعة صفر
أول نسخة لغوية لعنصر موجود؛ وتتطلب التعديلات اللاحقة رقم النسخة الموجب الحالي.

المفاتيح مولدة بصيغة `content/<item-id>/<en|ar|fr>/<revision-id>.md`. يُثبت الملف
المؤقت الخاص في المجلد نفسه، ثم يعاد تسميته ويثبت المجلد قبل مرجعه في SQLite،
وتثبت إدخالات المجلدات الأب الجديدة أيضاً. تفحص بصمة SHA-256 وحجم البايتات عند كل
قراءة؛ يفشل الملف المفقود أو التالف صراحة ولا يتحول إلى مقال فارغ. الجسم الفارغ
المحفوظ عمداً حالة مختلفة. تحصر واجهات جذور المجلدات في Go الوصول، وترفض قواعد
المسارات وفحوص الروابط الرمزية المسارات الخارجية والروابط. لا تعرض API المسارات الفعلية.

يمسك كل حفظ القفل المشترك بين العمليات `maintenance.lock` حتى اعتماد البيانات.
على النسخ الاحتياطي والتنظيف المستقبلي أخذ القفل الحصري نفسه. تحفظ اللقطة **كامل**
سجل المراجعات المشار إليه لا الملفات الحالية والمنشورة فقط. تقارن `InspectLocked`
المراجع والملفات وتبلغ عن المراجع غير السليمة والملفات اليتيمة دون حذف. قد تترك
الأخطاء والتعارضات وانقطاع إعادة التسمية ملفات يتيمة؛ لا تنظيف تلقائياً. لا تحذف
ملفات يدوياً أثناء تشغيل التطبيق أو النسخ الاحتياطي. استخدم الأوامر المنسقة في [دليل الاسترداد](operations/recovery.md).

قد يعني الفشل بعد الاعتماد نجاح الحفظ مع ضياع الرد؛ على مستدعي الأدوات الداخلية إعادة قراءة البيانات
قبل المحاولة. تسجل واجهة المحتوى نتائج منع التكرار ذرياً، ويمكن إعادة المفتاح والبيانات نفسيهما. تغطي الاختبارات حقن الأعطال قبل
إعادة التسمية وبعدها وتثبيت المجلد واعتماد SQLite، وبقاء المؤشرات قابلة للقراءة،
والتعارض وتعديل البيانات فقط ورفض الاجتياز والروابط والتلف والفقد واستبعاد الصيانة المتزامنة.

اختبر عبر `go -C backend test ./internal/storage ./internal/content`.
يتطلب البروتوكول نظام ملفات محلياً يدعم التثبيت الدائم للملفات والمجلدات؛ فشل التثبيت يلغي الحفظ.

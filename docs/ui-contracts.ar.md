# عقود حزمة الواجهة المشتركة

[English](ui-contracts.md) · [التوثيق](README.ar.md)

تضم الواجهة المشتركة الخطوط المحلية والرموز المولدة وThemeProvider وBrandStyle وI18nProvider. لا تزرع مالكاً أو محتوى.

يحتوي QuizQuestion معرّفات السؤال/الخيارات والنوع والنص المحلي فقط. يضيف QuizForReader اللغة ودرجة النجاح ونسخ quiz/content/path/epoch الدقيقة. توجد الخيارات الصحيحة والشروح فقط في QuizResult.feedback بعد تصحيح الخادم. يحمل QuizSubmission النسخ والإجابات ومفتاح idempotency، ويعيد المكون المفتاح نفسه بعد فشل شبكة مجهول النتيجة. يتولى الخادم التصحيح والتخزين وفرض الوصول.

حالات التحميل وفشله وفشل الإرسال وحد المعدل والنسخة القديمة صريحة. تعطل المدخلات أثناء الطلب ويمنع الإرسال المكرر. فشل الشبكة يحفظ الاختيارات؛ إعادة الاختبار بعد نتيجة فاشلة تمسحها بمفتاح جديد. تغير النسخة أو اللغة يعيد إنشاء المحاولة ويتجاهل الرد القديم. لا تظهر نسخة نتيجة قديمة رابط التالي بل تتطلب إعادة التحميل. يعرض رابط فعل تالٍ محلي فقط من نتيجة نجاح الخادم. يتلقى LockedLesson مقتطفاً نصياً عاماً صريحاً لا جسماً محمياً أو مكوناً اعتباطياً.

يسمح `pick(value, 'profile')` و`pick(value, 'label')` بالبديل الإنجليزي لهذين المجالين النصيين فقط. المحتوى المنشور نموذج مستقل محدد اللغة، وتسميات التصنيف نصوص محلولة مسبقاً. تحتاج ترجمة مقال/doc/درس/اختبار غير المتاحة إلى انتقال صريح للغة متاحة. يفرق resolveLabel() بين التجاوز الغائب والفارغ صراحة: FR/AR الفارغ يستخدم الإنجليزية الفعلية وإزالة التجاوز تعيد ترجمة الحزمة. نصوص العد تستعمل Intl.PluralRules بما فيه zero/one/two/few/many/other العربية. يعرض label() ومكون Label اللغة والاتجاه الحقيقيين للبديل.

يشمل Profile هوية وسائط/صورة منفصلة وتسميات روابط محلية بمعرّفات ثابتة وظهور وأيقونات مسموحة وفعل رئيسي وغلاف/بديل/تركيز اختياري وخبرات مرتبة بقيم سنة-شهر ومرجع About والتواصل/التذييل وظهور الأقسام وأعدادها. يخفي Now الفارغ. لا يستورد التطبيق ملفاً شخصياً ثابتاً؛ عينات الاختبار منفصلة عن محتوى الإنتاج.

من الجذر:

```sh
node scripts/project.mjs check
node scripts/project.mjs build
node frontend/tests/visual.cjs
```

يتطلب الفحص المرئي Playwright Chromium (`cd frontend && npx playwright install --with-deps chromium` على مضيف CI مدعوم). يعرض الأصول المبنية للغات الثلاث بعرض320/1280px وفاتح/داكن ويفحص اللغة/الاتجاه/التجاوز ويلتقط صوراً للفحص. تختبر DOM أخطاء الاختبار وإعادته ونسخه وقواعد النصوص. لا تثبت العينات أو الصور تصحيح الخادم أو WebAuthn أو توافق الأجهزة.

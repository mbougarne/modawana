# قارئ Markdown المشترك (Markdown Reader)

[English](markdown-reader.md) · [التوثيق](README.ar.md)

يوفر التطبيق المكون المشترك `frontend/src/features/markdown/MarkdownReader.tsx` لخدمة القراءة العامة ومعاينات المالك الخاصة. يتوفر مسار المعاينة المحمية للمالك على الرابط `/{locale}/admin/preview/{key}/{contentLocale}` ويستخدم المكون نفسه تماماً مع تمرير لغة المحتوى الدقيقة. لا تمنح معاينة المالك أي وصول عام للزوار ولا تُنشئ أي سجل لتقدم التعلّم.

يدعم عارض النصوص جداول وقوائم تنسيق GitHub Flavored Markdown (GFM)، وكتل الأكواد البرمجية المحددة مع إشعار بنجاح النسخ، والمعادلات الرياضية المعالجة عبر KaTeX MathML، والخلاصات الرئيسية الاختيارية (takeaways) التي يكتبها المؤلف بنفسه. تمر هذه الخلاصات عبر المسار البرمجي المعالج نفسه؛ ولا يقوم التطبيق بتوليدها تلقائياً. يُعطّل العارض كود HTML الخام، وملفات MDX، والسكربتات، وتضمينات iframe تماماً. كما يُعطّل خيار الثقة في كود المعادلات الرياضية (`trust: false`) وتكون أبعادها وأقصى حجم لتوسعتها مقيدة بدقة منعاً للهجمات. يبلغ الحد الأقصى لحجم ملف Markdown المسموح به 1 ميغابايت (1 MiB). تظل كتل الأكواد البرمجية والمعادلات باتجاه LTR دائماً حتى داخل النصوص العربية، وتُعرض الجداول القابلة للتمرير داخل حاوية يمكن التركيز عليها عبر لوحة المفاتيح. ويتبع عرض منطقة القراءة وتحجيم الوسائط قواعد نظام التصميم المشتركة.

يجب أن تطابق كافة الصور معرف وسائط صالحاً بطول 32 محرفاً ومدرجاً في بيان الوسائط المصرح به والمرفق مع المحتوى؛ حيث يُعاد بناء مسار الرابط برمجياً بصيغة `/media/{id}`. ولا يقوم التطبيق بجلب أي صور خارجية أو صور غير مدرجة في البيان المعتمد. وعند وضع رابط مستقل لملف فيديو معتمد في البيان، يقوم العارض بتقديم مشغل فيديو متكامل مع عناصر التحكم، وصورة غلاف ملصقة (poster) مصرح بها اختيارياً، ومسارات ترجمة نصية VTT مصرح بها، مع إمكانية طي وكشف النص المفرغ (transcript) والترجمة النصية. وتستخدم ملفات PDF روابط تنزيل آمنة. وعند فقدان ملف الوسائط أو تعذر تحميله، تظهر رسالة تنبيه واضحة ومترجمة للمستخدم. ويعيد الخادم التحقق من الصلاحيات مع كل طلب لملف وسائط؛ فمجرد وجود الملف في البيان لا يمنح تجاوزاً لصلاحيات الوصول. ترفض الروابط محارف التحكم، وعناوين URL المتضمنة لبيانات اعتماد، والمخططات غير الآمنة؛ ولا يُستخدم كود HTML كمنفذ خلفي لتمرير أي عناصر.

يغطي ملف الاختبارات `frontend/tests/markdown.test.cjs` فحص المدخلات الخبيثة، ومخططات الروابط، وكافة اللغات المدعومة، والأكواد، والمعادلات، وتنسيق GFM، والخلاصات، وضوابط الوسائط المدارة. ويتحقق سكربت `scripts/smoke-configuration.mjs` (المستدعى عبر `scripts/smoke-auth.mjs`) من المعاينات المقدمة فعلياً عبر خادم Go، وسياسة أمان المحتوى (CSP)، وتصيير MathML، والجداول، ومسارات الفيديو، وحجب المسارات والوسائط الخاصة عن غير المصرح لهم. وتعتمد كافة صفحات المقالات والوثائق العامة على هذا العارض المشترك حالياً. والاستثناء الوحيد المعتمد هو الحزمة `backend/internal/render`، وهي عارض Markdown على جانب الخادم المخصص لخطة الانتقال إلى القوالب ([القرار المعماري 0002](decisions/0002-server-rendered-themes.ar.md)): فما دام المساران موجودين معاً، يجب أن يبقيا في تطابق تام عبر الاختبارات المرجعية المشتركة في `backend/internal/render/testdata/fixtures` والسكربت `scripts/markdown-parity.mjs`، ويُزال مسار المتصفح صفحةً صفحة مع انتقال الصفحات العامة. لا تُنشئ أي مسار آخر لمعالجة Markdown.

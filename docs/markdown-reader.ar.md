# قارئ Markdown المشترك

[English](markdown-reader.md) · [التوثيق](README.ar.md)

يوفر التطبيق المكوّن `frontend/src/features/markdown/MarkdownReader.tsx` للقراءة العامة ومعاينة المالك. تقع المعاينة المحمية في `/{locale}/admin/preview/{key}/{contentLocale}` وتستخدم المكوّن نفسه بلغة المحتوى الدقيقة. لا تمنح معاينة المالك وصولاً عاماً ولا تنشئ تقدم تعلم.

يدعم العارض جداول وقوائم GFM والشيفرة مع إفادة النسخ والمعادلات باستخدام KaTeX MathML والخلاصات الاختيارية التي يكتبها المؤلف. تمر الخلاصات بالمسار نفسه ولا يولدها التطبيق. يُعطل HTML الخام وMDX والبرامج وiframe. ثقة المعادلات false وتوسعتها وحجمها محدودان. حد Markdown هو 1 MiB. تبقى الشيفرة والمعادلات LTR بالعربية، وتُمرّر الجداول داخل منطقة تقبل تركيز لوحة المفاتيح. يتبع عرض القراءة وتحجيم الوسائط قواعد التصميم المشتركة.

يجب أن تطابق الصور معرّف وسائط من 32 محرفاً في البيان المخوّل؛ يُعاد بناء الرابط `/media/{id}`. لا تُجلب الصور البعيدة أو غير المدرجة. يعرض رابط مستقل لفيديو في البيان عناصر التحكم وملصق صورة مخوّلاً اختيارياً وVTT مخوّلاً وتعليقاً ونصاً مفرغاً قابلاً للكشف. تستخدم ملفات PDF روابط تنزيل آمنة. تظهر إفادة مترجمة للوسائط المفقودة أو الفاشلة. يعيد الخادم فحص الوصول في كل طلب وسائط؛ البيان ليس تجاوزاً للتخويل. ترفض الروابط محارف التحكم وبيانات الاعتماد والمخططات غير الآمنة؛ لا يمثل HTML طريقاً بديلاً.

يغطي `frontend/tests/markdown.test.cjs` المدخلات الضارة ومخططات الروابط واللغات الثلاث والشيفرة والمعادلات وGFM والخلاصات والوسائط المضبوطة. يتحقق `scripts/smoke-configuration.mjs`، المستدعى من `scripts/smoke-auth.mjs`، من المعاينات المقدمة فعلياً عبر Go وCSP وMathML والجداول ومسارات الفيديو ومنع المسارات والوسائط الخاصة. تعيد صفحات المقالات والوثائق العامة استخدام العارض ؛ لا تضف مسار Markdown ثانياً.

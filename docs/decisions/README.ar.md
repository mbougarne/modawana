# سجلات القرارات المعمارية

[English](README.md) · [التوثيق](../README.ar.md)

يضم هذا المجلد القرارات المعمارية المعتمدة في مشروع مدوّنة. كل سجل مرقّم،
وثنائي اللغة (ملفان مرتبطان بالإنجليزية والعربية)، ويصف قراراً واحداً: سياقه،
والقرار نفسه، والنموذج الأمني، ومسار الانتقال من الشيفرة الحالية، وخطة تسليم
مرحلية. تُعدَّل السجلات بسجلات لاحقة ولا يُعاد كتابتها، حتى يبقى تاريخ كل
قرار مقروءاً.

> ملاحظة: الترجمة العربية لهذه السجلات بانتظار مراجعة لغوية من متحدث أصلي.

# Architecture decision records

[العربية](README.ar.md) · [Documentation](../README.md)

This folder holds accepted architecture decisions for Modawana. Each record is
numbered, bilingual (linked English/Arabic pairs), and describes one decision:
its context, the decision itself, the security model, the migration path from
the current code, and a staged delivery plan. Records are amended by follow-up
records, not rewritten, so the history of a decision stays readable.

| Record | Decision |
| --- | --- |
| [0001](0001-wasm-plugin-host.md) | WebAssembly plugin host API on a pure-Go runtime |
| [0002](0002-server-rendered-themes.md) | Server-rendered public pages and theme packs |

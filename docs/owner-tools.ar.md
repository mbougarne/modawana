# الكتابة وإدارة المحتوى

[English](owner-tools.md) · [التوثيق](README.ar.md)

ادخل من `/{locale}/login` واستخدم لوحة المالك. تدعم الواجهة العربية والإنجليزية
والفرنسية. تتطلب كل المسارات جلسة كاملة، وتتطلب الكتابة أيضاً الأصل نفسه وCSRF.

## الكتابة والنشر

1. افتح **المحتوى** وأنشئ مقالاً أو درساً أو مستنداً. أدخل العنوان واختر لغة
   المحتوى. تقترح العناوين الجديدة روابط يمكنك تعديلها قبل النشر. تبقى روابط
   المحتوى المنشور ثابتة حتى بعد إلغاء نشره.
2. استخدم **الكتابة** و**المعاينة** و**الوسائط** و**الاختبار** و**التفاصيل**
   لتحرير مسودة العمل نفسها. لا اختبارات للمستندات. تستخدم المعاينة المنقسمة
   عارض Markdown العام، ويُمرر المحتوى الطويل داخل المحرر.
3. اختر وسائط أو الصقها أو أسقطها أو اختر ملفاً من المكتبة. أضف النص البديل
   وأدرج مرجع `/media/{id}` الثابت واختر غلافاً اختيارياً. للفيديو صورة ملصق
   مرفوعة وترجمة VTT ونص مفرغ عادي.
4. ينشئ **حفظ المسودة** مراجعة ثابتة. يحفظ **حفظ ونشر** العمل الحالي أولاً
   ثم ينشر مراجعته وإصداره الدقيقين. لا ينشر الحفظ الملغى أو الفاشل نسخة أقدم.
   ابدأ عنصراً آخر عبر **محتوى جديد**.

يفحص النشر وإلغاؤه واسترجاع التاريخ الإصدارات. ينشئ استرجاع التاريخ مسودة جديدة
ولا يغير النسخة الحية. عند التعارض صدّر العمل غير المحفوظ قبل إعادة التحميل؛
لا يكتب المحرر فوق عمل أحدث بصمت. تعيد محاولة الحفظ المتطابقة مفتاح العملية نفسه.

تسجل الترجمات مراجعة المصدر وتحتاج مراجعة قبل النشر. في ترجمة الاختبار يحدّث
**استخدام تقييم المصدر الحالي** البنية المرجعية مع حفظ النصوص ذات المعرّفات
المطابقة؛ راجع الترجمة كلها مجدداً.

ترشح قائمة المحتوى باللغة والنوع وحالة النشر والنص مع تقسيم الصفحات.
يعرض النشر الجماعي تأكيداً ويستخدم الإصدارات المحددة الدقيقة. يرفض الخادم
الاختيار القديم أو غير المتاح أو غير المراجع.

## المجموعات والفئات والوسوم

أنشئ مجموعة أو افتحها واضبط تفاصيلها المحلية وابحث بعنوان المحتوى واختر نتيجة
واضغط **إضافة**. كرر ورتب ثم **حفظ المجموعة**. تتحول المقالات المختارة لدروس
أو مستندات حسب نوع المجموعة بعد التأكيد. يبقى المنشور منشوراً والمسودات خاصة.
يحفظ الزر التفاصيل والترتيب والخطة وتفعيلها معاً. تعرض الخيارات المتقدمة عمليات
الخطة والإصدار والتقدم المنفصلة. لا ينتقل الأعضاء المنشورون أو يختفون بصمت.

للدرس اختر مجموعة تعلم من التفاصيل واحفظ. ينشر **النشر مع خطة المسار** الدرس
ويفعّل الخطة المطابقة ذرياً. عند غياب الخطة يجهز التدفق خطة خاصة مرتبة بعد التأكيد.
النشر وحده لا يفعّل الخطة. فعّل ظهور المجموعة بلغتها و**الملف ← إظهار مسارات
التعلم** لعرضها في الرئيسية.

يمكن إعلان درس خاص صراحة بأنه «قريباً» في خريطة المسار؛ يبقي الإعلان الفارغ
الدرس خاصاً. لا يمنح الملخص وصولاً إلى الجسم.

للفئات والوسوم مفاتيح ثابتة وتسميات وروابط محلية. أنشئها من التصنيف أو منتقي
المحرر. لا يظهر مولد للمفتاح الثابت. يتغير نوع العنصر عبر تحويل محرر المالك
المحفوظ وتأكيده؛ تبقى قيود النشر والمجموعات والاختبارات على الخادم مطبقة.

## الاختبارات وبوابات الدروس

تدعم اختبارات المقال والدرس 1–20 سؤالاً مفرد الاختيار أو متعدد الخيارات أو
صح/خطأ، و2–8 خيارات ونقطة لكل سؤال ودرجة نجاح صحيحة وإعادات غير محدودة.
تحفظ المعرّفات الثابتة المعنى عند الترتيب والترجمة. يرتبط الاختبار بمراجعة
المحتوى الدقيقة؛ لا يغيّر تحرير المسودة اختباراً حياً.

يصحح **حفظ الاختبار وتجربته** النسخة المحفوظة خصوصياً في Go دون تقدم للقراء.
يؤكد **حفظ التقييم ومراجعته** ذلك التقييم الدقيق. لقفل الدروس اللاحقة رتب
درسين على الأقل وراجع الاختبار السابق وفعّل شرط الفتح في مسودته وانشر مع خطة
المسار المطابقة بعد تأكيد الأثر. لا يقفل درس الاختبار نفسه. اختبارات المقالات
تدريبية ولا تنشئ بوابات. إعادة المسار لكل القراء عملية منفصلة تتطلب مصادقة حديثة.

لا تنشأ هويات القراء إلا بتفاعل صريح لا بزيارة الصفحة. التقدم خاص بالمتصفح
وقد ينتهي أو يعاد ضبطه. تظهر الإجابات والشروح بعد تصحيح الخادم فقط عند تفعيل التغذية الراجعة.

## الوسائط وإعدادات الموقع

ترشح المكتبة الصور والفيديو وPDF وVTT. لا يحذف ملف تشير إليه مراجعة محتوى أو
إعداد أو سجل محفوظ. إذا كشف مرجع عام ملفاً، فلن يجعل إلحاقه بدرس مقفل عنوانه
خاصاً. راجع تحذير إعادة الاستخدام العام قبل مشاركة مادة محمية.

استخدم **الإعدادات** للألوان والشعار و**الملف** للمقدمة والصورة وحالياً والخبرة
والروابط و**النصوص** لتسميات الواجهة. المعاينة والإلغاء لا يغيران الموقع العام؛
احفظ الإصدار المراجع وطبقه. يتحكم **الإجراء الرئيسي** في زر الرئيسية والنبذة؛
تغيير الأيقونة يغير الرمز فقط. تظهر روابط GitHub وLinkedIn وRSS المضبوطة الظاهرة
في التذييل أيضاً. يمكن لنص الاتصال بالتذييل استبدال الدعوة الافتراضية المرتبطة بالبريد.

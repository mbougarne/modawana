# الصفحات العامة

[English](public-pages.md) · [واجهة API](api/README.ar.md)

يربط الموقع العام بالإعدادات النشطة والمراجعات
المنشورة. تقدّم عملية Go هيكل HTML وواجهة API، ويبني Webpack تطبيق React.
يتضمن الهيكل عنواناً ووصفاً ورابطاً أساسياً وبدائل لغوية منشورة وبيانات Open Graph
مع تهريب النصوص. ما زال جسم المقال يحتاج JavaScript؛ لا يُدّعى العرض من الخادم
أو فهرسة الأجسام دون JavaScript.

## المسارات والظهور

استبدل `en` بـ`ar` أو `fr` للمسارات الصريحة للغات الأخرى.

| المسار | المحتوى |
| --- | --- |
| `/en` | المقدمة والصورة والغلاف والأنشطة وملخصات الكتابة والتعلم النشطة |
| `/en/about` | الملف المهني والاتصال ونص التعريف المنشور الاختياري بصيغة Markdown |
| `/en/writing`, `/en/search` | البيانات المنشورة ومرشحات الرابط وتقسيم النتائج بالمؤشر |
| `/en/articles/{slug}` | المقال المنشور |
| `/en/learn`, `/en/docs` | مسارات التعلم أو أدلة الوثائق النشطة والظاهرة وغير الفارغة |
| `/en/learn/{path}`, `/en/docs/{guide}` | الفهرس العام النشط والمرتب |
| `/en/learn/{path}/{slug}`, `/en/docs/{guide}/{slug}` | العضو المنشور مع التنقل السابق والتالي |
| `/en/doc/{slug}` | وثيقة منشورة لم يُفعّل أو يُظهر دليلها في اللغة بعد |

لا يصح مسار الوثيقة المستقل إلا عند غياب مسار دليل نشط في اللغة؛ يصبح مسار
الدليل أساسياً عند توفره. يعيد النوع أو المجموعة الخطأ والعضو غير المنشور واللغة
المفقودة والصفحة المجهولة 404 فعلياً. تُرمّز الأسماء العربية في الروابط الأساسية.
تُرفض الفواصل المرمّزة والشرطة المائلة العكسية والتنقل بالنقاط. تستخدم الروابط
الأساسية `BLOG_BASE_URL` وليس ترويسات Host المحوّلة. تبقى مسارات المالك الخاصة
محمية بالمصادقة وnoindex.

يستخدم `GET /api/v1/public/page?path=/en/articles/{slug}` محلّل المسارات نفسه
المستخدم لـHTML. يعيد `kind` و`locale` و`url` و`title` و`summary` و`alternatives`
ومحتوى `content` أو `collection` الاختياري. يعيد الدرس المقفل 403 مع إسقاط آمن
للصفحة دون Markdown أو وسائط ومع noindex، وكذلك HTML. تختلف بنية 403 لهذه
النقطة عن `{error,teaser}` لنقطة المحتوى الأقدم. تؤدي الملفات المفقودة أو التالفة
إلى خطأ (503 في HTML و500 في API)، لا نجاح فارغ أو بديل من المسودة. لا تحوّل
كوكيز المالك الصفحة العامة إلى معاينة خاصة.

تشير روابط البدائل وعناصر المجموعات الآن إلى الصفحات الأساسية، وتبقى نقاط JSON
للمحتوى متاحة. تقتصر البدائل على اللغات المنشورة ذات مسار عام قابل للحل. تعرض
الترجمة المفقودة خيارات لغة صريحة للموقع دون استبدال المحتوى بالإنجليزية خفية.
يبقى الرجوع اللغوي للملف وتسميات الواجهة مسموحاً، وتُعلّم لغة نصوص الملف واتجاهها
عند عرضها.

يعيد `GET /api/v1/public/collections?locale=en&kind=learning&limit=20&cursor=…`
البنية `{items,next_cursor}`. النوع `learning` أو `docs` والحد 1–20. يستبعد
مؤشر المفتاح المستقر الفهارس الفارغة وغير النشطة والخاصة. تعرض البطاقات والفهارس
أعداد المنشور والمعلن والإنجاز المحفوظ بالخادم. العناصر القادمة نص دون مفتاح
أو اسم مسار أو رابط أو عنوان مسودة. تخفي المواضع العامة الفجوات الخاصة. يقرر
الخادم الإتاحة والقفل والتصحيح والإنجاز. يربط `ReaderLearning` الاختبارات وروابط
المتطلبات وتحديد المقروء وإعادة تقدم المتصفح بـ[واجهة التعلم](api/learning.ar.md)؛
ينشئ تفاعل صريح هوية المتصفح.

## الأرشيف والقراءة

يجتمع النوع والتصنيف والوسم والبحث بمنطق AND. تحفظ الروابط `kind` و`category`
و`tag` و`q` و`cursor` ويستعيدها الرجوع. يزيل الضغط الثاني الوسم المحدد. تُلغى
الطلبات وتُتجاهل الاستجابات القديمة؛ تتاح إعادة المحاولة عند الفشل ومسح المرشحات
للنتائج الفارغة المرشحة. يبحث SQLite في العناوين والملخصات المنشورة لا أجسام
Markdown. تشمل القوائم التاريخ والسنة والنوع والتصنيف والوسوم المحلية وحالة
قفل آمنة وتقديراً اختيارياً لمدة القراءة.

يخزن الترحيل 0007 المدة المقدرة عند كتابة المراجعة: كلمات Markdown المفصولة
بمسافات بمعدل 200 كلمة في الدقيقة، مع التقريب للأعلى. تحتفظ المراجعات القديمة
الثابتة بصفر (غير معروف) فلا يعرض الاستكشاف تقديرها، وكذلك العناصر المقفلة.
يمكن لقارئ الصفحة اشتقاقه من الجسم المصرح به. لا يقرأ الاستكشاف الملفات لحسابه.
هذا تقدير وليس وعداً بسرعة القراءة.

يستخدم القارئ معالجة Markdown والوسائط الآمنة نفسها المستخدمة للمعاينة.
الخلاصة نص يكتبه المؤلف في Markdown لا نثر مولد. تأتي هوية المؤلف وحقائق الملف
من الإعدادات النشطة، وتعكس تواريخ الأدلة آخر نشر. لا تُزرع محتويات غير منشورة
أو أمثلة حزمة الواجهة أو بيانات اعتماد.

## التحقق

شغّل `node scripts/project.mjs check` و`go -C backend test -race ./...`
و`node scripts/project.mjs build`. بعد تثبيت Chromium لـPlaywright شغّل
`node scripts/smoke-production.mjs` و`node scripts/smoke-auth.mjs`؛ يستدعي
الأخير `smoke-public.mjs` ببيانات مؤقتة للمالك والمحتوى.

تغطي اختبارات Go النوع والعضوية الأساسية وأسماء Unicode والبيانات المنشورة فقط
والقفل وnoindex وعزل المسودات وتلف الملفات. تغطي اختبارات المتصفح التثبيت الفارغ
بعروض 320 و390 و1280 بكسل واللغات الثلاث والمظهرين، والملف المهيأ والقارئ
والفهارس، وإغلاق القائمة بـEscape وإعادة التركيز، ومرشحات الرابط والرجوع
والطلبات القديمة البطيئة وإعادة المحاولة والترجمات المفقودة. تُحفظ الصور في
`frontend/test-results/` ويرفعها CI للمراجعة. تبقى WebAuthn الافتراضية محاكاة؛
يلزم التحقق على الأجهزة الحقيقية.

## مطابقة الرأس

يعيد الرأس العام استخدام التنقل المستدير والأدوات الدائرية المشتركة في Version B. تحتوي روابط الأقسام على النص فقط. الشعار النصي أو الأحرف أو الصورة رابط بسيط للرئيسية دون قائمة أو سهم أو خلفية زر مستدير. ترتيب الأدوات هو البحث ثم اللغة ثم المظهر؛ ويوفر زر قائمة منفصل التنقل على الهاتف. يفتح زر اللغة خيارات EN/AR/FR وينقل التركيز لأول خيار ويدعم Escape مع إعادة التركيز. تبقى قواعد توفر ترجمة المحتوى مطبقة. يصل المالك المصادق عليه للوحة التحكم من التذييل.

## مطابقة B Personal

تعتمد الواجهة العامة المكونات المعتمدة: إجراء أساسي وروابط اجتماعية وRSS، صفوف الآن، كتابات بالسنوات ورابط الكل، بطاقات تعلم كاملة، بحث مدور مباشر، نبذة بعمود للصورة والخبرة وعمود للسرد والبريد والروابط، وبطاقة كاتب وشريط دروس وتنقل. تظل كل الحالات من الخادم، ولا تظهر أجسام مقفلة أو إعلانات خاصة أو تقدم مخترع.

## مراجعة القراءة

تعرض الكتابات مرشحات الفئات والوسوم دون نموذج بحث إضافي؛ يستعمل زر البحث في الرأس. يستعمل رأس المقال والدرس شارة الفئة والنوع والعنوان والملخص وصورة واسم الكاتب وتاريخ النشر مع وقت القراءة التقريبي الحالي (كلمات Markdown المحفوظ / 200 مع التقريب للأعلى، دون ذكاء اصطناعي). تحذف بادئة التحديث وروابط اللغة السفلية، مع حفظ اللغات المنشورة الصريحة في قائمة الرأس. تضاف مسافة أعلى بطاقة التقدم وأسفلها، بما فيها بجانب زر تحديد كمقروء. يحل نص الملف الشخصي ← الاتصال ← التذييل محل جملة الاتصال الافتراضية؛ امسحه لاستعادة الدعوة الافتراضية المرتبطة بالبريد. لا تتغير قيم الملف المحفوظة.

## روابط التذييل

يربط التذييل الكتابات والتعلم والتوثيق باللغة الحالية ثم أول رابط ملف صالح وظاهر لكل أيقونة GitHub وLinkedIn وRSS. تحذف الوجهات الغائبة؛ اختيار RSS لا ينشئ نقطة تغذية. يبقى تنقل المالك مشروطاً بالجلسة. يتبع تنسيق الزر الأساسي في الرئيسية والنبذة الإجراء الرئيسي في الملف؛ لا يحدد الرمز لون الزر. [إعداد المالك](owner-tools.ar.md).

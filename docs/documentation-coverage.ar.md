# تغطية التوثيق المزدوج

[English](documentation-coverage.md) · [الفهرس](README.ar.md)

تعتمد أدلة المشروع إما على أزواج مترابطة من الملفات باللغتين العربية والإنجليزية، أو على أقسام ثنائية اللغة بالكامل. وتُحفظ نصوص تراخيص الطرف الثالث الأصلية كما هي دون ترجمة. يوثق ملف [سجل الجرد](documentation-inventory.json) كافة ملفات Markdown المعتمدة في المشروع ومستوى تغطيتها اللغوية، مع استبعاد نواتج البناء، والملاحظات الشخصية، والتبعيات البرمجية.

بعد إضافة أدلة توثيقية جديدة أو حذف أدلة سابقة، نفّذ الأمرين التاليين:

```sh
node scripts/check-docs.mjs --write
node scripts/check-docs.mjs
```

يتحقق الفاحص الآلي من وجود الملفات المقابلة لكل لغة، وروابط التنقل اللغوي، وصحة مسارات الملفات المحلية، ومطابقة سجل الجرد بدقة. احرص على مراجعة تكافؤ المعنى، وصحة الأوامر، والقيود، والعقود بصورة مستقلة؛ فمجرد اكتمال تغطية الملفات لا يضمن صحة المعنى الدلالي للترجمة. تجدر الإشارة إلى أن نصوص واجهة المستخدم تدعم اللغة الفرنسية أيضاً إلى جانب العربية والإنجليزية.

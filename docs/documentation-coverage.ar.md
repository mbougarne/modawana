# تغطية التوثيق

[English](documentation-coverage.md) · [الفهرس](README.ar.md)

تستخدم أدلة المشروع أزواجاً عربية وإنجليزية أو أقساماً كاملة باللغتين. تحفظ
أصول تراخيص الأطراف الأخرى دون ترجمة. يسرد [الجرد](documentation-inventory.json)
ملفات Markdown المدارة وتغطيتها اللغوية؛ يستبعد البناء والملاحظات الخاصة والاعتماديات.

بعد إضافة الأدلة أو حذفها شغّل:

```sh
node scripts/check-docs.mjs --write
node scripts/check-docs.mjs
```

يتحقق الفاحص من النسخ المقابلة والتنقل اللغوي والملفات المرتبطة وحداثة الجرد.
راجع تكافؤ المعنى والأوامر والحدود والعقود مستقلاً؛ وجود الملف لا يثبت دقة الترجمة.
تشمل نصوص المنتج الفرنسية أيضاً.

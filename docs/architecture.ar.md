# البنية

[English](architecture.md) · [التوثيق](README.ar.md)

Modawana تطبيق نشر لمالك واحد. تخدم عملية Go واحدة ملفات React المبنية
وAPI من الأصل نفسه خلف وكيل HTTPS. تحفظ SQLite البيانات الوصفية والحالة،
وتحفظ أجسام Markdown والوسائط كملفات على قرص محلي دائم. لا توجد خدمة Node إنتاجية
أو تسجيل عام أو قاعدة خارجية أو API متصفح عبر أصول مختلفة.

| المكون | المسؤولية |
| --- | --- |
| `backend/cmd/blog` | خادم HTTP وأوامر الإعداد والصيانة والنسخ والاسترداد |
| `backend/cmd/publisher` | CLI للنشر المحدد الصلاحيات والتوصيل الدائم ومجدول الدروس الاختياري |
| `backend/internal` | المصادقة والتفويض والمحتوى والإعدادات والوسائط والاختبارات والتخزين |
| `backend/migrations` | ترحيلات SQLite مرتبة ذات بصمات |
| `frontend/src` | مسارات React ولوحة المالك والقارئ وعميل API وعرض Markdown الآمن |
| `ui/src` | المكونات وتسميات EN/AR/FR والمزودات والخطوط والرموز المولدة المشتركة |
| `design-system` | الرموز المرجعية ومولداتها وملف أنماط المكونات المشترك |
| `deploy` | أمثلة Docker وCompose والوكيل العكسي وsystemd |
| `scripts` | أدوات التطوير والجودة والنشر والنسخ والإصدارات |

## التخزين والنشر

يصل Go وحده إلى القاعدة والملفات المدارة. تستخدم SQLite مفاتيح خارجية وWAL
ومهلة انتظار محدودة ومعاملات قصيرة. شغّل مثيلاً واحداً على نظام ملفات محلي؛
لا تُدعم أنظمة الملفات الشبكية أو النسخ الأفقية. يمنع قفل التشغيل خادمين من
استخدام جذر البيانات نفسه.

ينشئ كل حفظ مراجعة Markdown ثابتة. تسجل القاعدة مسارها النسبي وبصمتها ومراجعتها
الأصلية. يختار النشر مراجعة محفوظة بعينها؛ لا يغيّر تحرير المسودة النسخة الحية.
ترفض الإصدارات المتفائلة التعارض، وتجعل مفاتيح إعادة الطلب المحاولة المتطابقة
دون تكرار المراجعات. الترحيلات إضافية ذات بصمات.

تنشر الترجمات مستقلة بعد مراجعتها مقابل المصدر. عند غياب ترجمة المحتوى يظهر
تنقل صريح بين اللغات ولا يُستبدل الجسم بصمت. للملف العام ونصوص الواجهة قواعد بديلة موثقة.

## حدود الوصول

يتطلب وصول المالك مفتاح مرور أو كلمة مرور مع TOTP. يتيح الاسترداد تسجيل عوامل
مقيداً، ويشترط دخولاً ناجحاً بالعامل البديل. لرموز الناشر صلاحيات مستقلة للمسودة
والوسائط والاختبار والنشر وحدود للمجموعات. ترث منح OAuth حدود الرمز الأب ويمكن إلغاؤها مستقلة.

تبقى الدروس المنشورة المقفلة خاضعة لمتطلبات يتحقق منها الخادم. تحمي السياسة نفسها
الأجسام والوسائط والبيانات والاكتشاف والمعاينة والخلاصات وبطاقات المشاركة.
إخفاء CSS ليس تفويضاً. هويات التعلم المرتبطة بالمتصفح منفصلة عن جلسات المالك.
تصحيح الاختبارات والتقدم داخل معاملات؛ لا تُرسل مفاتيح الإجابة مع أسئلة القارئ.

تعرض الواجهة Markdown بمسار آمن موحد للمعاينة والقراءة. لا يُدعم HTML الخام
أو MDX التنفيذي أو البرامج العشوائية أو التضمينات البعيدة غير المضبوطة.
تستبعد السجلات الأسرار والاستعلامات والمسودات. تستخدم كتابة المتصفح الأصل نفسه
وCSRF؛ يستخدم النشر الآلي رموز bearer محددة الصلاحيات.

## الإعدادات والتشغيل

الهوية والملف والنصوص إعدادات ذات إصدارات. أصول التشغيل ومفاتيح المصادقة ومسارات
الملفات إعداد خاص لا يُضمّن في المتصفح. يخدم الإنتاج أصول البناء المدرجة في البيان فقط.

تجمع النسخة الاحتياطية لقطة SQLite منسقة وكل الملفات المرجعية. تبطل الاستعادة
الاعتمادات وتقدم التعلم وتدخل الصيانة وتتطلب اختبار التسجيل الجديد قبل الاستئناف.
الاستيراد والتصدير صيغة نقل محتوى منفصلة تنتج مسودات فقط. راجع [الاسترداد](operations/recovery.md).

يعيد [MCP](integrations/mcp-oauth.md) و[توصيل الدروس](integrations/lesson-delivery.ar.md)
الاختياريان استخدام قواعد الناشر. Notion وجهة مستقلة دون مزامنة محتوى ثنائية
تلقائية. يجري التوليد المجدول في عملية الناشر باعتمادات مهيأة منفصلة.

للعقود المفصلة راجع [الإعدادات والتعلم](architecture-appendix-configurable-learning.ar.md)
و[API](api/README.ar.md) و[الواجهة](ui-contracts.ar.md) و[التصميم](design.ar.md).

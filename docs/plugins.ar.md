# إضافات WebAssembly

[English](plugins.md) · [التوثيق](README.ar.md) · [القرار المعماري 0001](decisions/0001-wasm-plugin-host.ar.md)

- حالة الترجمة: بانتظار مراجعة لغوية من متحدث أصلي

يستطيع الخادم تحميل إضافات WebAssembly ‏(WASI) يعتمدها المالك، وفق
[القرار المعماري 0001](decisions/0001-wasm-plugin-host.ar.md). توثّق هذه الصفحة
سطح المرحلة 1: تخطيط مجلد الإضافة، والبيان (manifest)، ومسار اعتماد المالك،
وضمانات العزل. تُكتب إضافات المرحلة 1 بلغة Go وتُجمَّع بـ
`GOOS=wasip1 GOARCH=wasm`؛ أما سلسلة أدوات TypeScript فتأتي في مرحلة لاحقة.

## تخطيط المجلد

الإضافة مجلد واحد داخل جذر البيانات، خارج مجلدي الشيفرة والإصدار:

```
$BLOG_DATA_ROOT/plugins/{slug}/
├── manifest.json   إلزامي، بحد أقصى 64 كيبيبايت
├── plugin.wasm     وحدة WASI المسماة في "module"، بحد أقصى 32 ميبيبايت
└── …               ملفات ثابتة اختيارية (تُحسب لها بصمات، ولا تُقدَّم بعد)
```

اسم المجلد هو هوية الإضافة ويجب أن يطابق حقل `slug` في البيان. يضع المشغّل
هذه الملفات بنفسه (عبر SSH مثلًا)؛ لا يكتبها الخادم أبدًا ولا يحذفها. تُرفض
الروابط الرمزية والملفات غير الاعتيادية، وكذلك ما يزيد على 256 ملفًا أو
64 ميبيبايت إجمالًا.

## البيان (manifest)

ملف `manifest.json` هو JSON صارم ومُرقَّم الإصدار: تُرفض الحقول غير المعروفة.

```json
{
  "schema_version": 1,
  "host_api_version": 1,
  "slug": "example",
  "name": "Example plugin",
  "version": "0.1.0",
  "description": "اختياري، بحد أقصى 500 حرف.",
  "module": "plugin.wasm",
  "capabilities": ["hooks", "routes", "storage"],
  "hooks": [{ "name": "content.rendered_meta", "version": 1 }],
  "routes": [{ "method": "GET", "path": "/hello", "public": true }]
}
```

- يحدد `host_api_version` إصدار واجهة المضيف الذي تتطلبه الإضافة. يقدّم هذا
  الملف التنفيذي الإصدار 1 ويرفض المتطلبات الأحدث.
- يمكن أن يعلن حقل `capabilities` في المرحلة 1 عن `hooks` و`routes`
  و`storage` فقط. كل صلاحية أخرى في جدول القرار المعماري (settings، jobs،
  http_fetch، secrets، content_read، mcp_tools) تُرفض حتى المرحلة التي
  تقدّمها. يجب إعلان الصلاحية لاستخدامها واستخدامها عند إعلانها.
- يشترك حقل `hooks` في نقاط الربط المسماة مع إصدار العقد (بحد أقصى 16).
- يعلن حقل `routes` عن معالجات يثبّتها المضيف تحت `‎/plugins/{slug}{path}`
  عندما تكون `public`، وتحت `‎/api/v1/plugins/{slug}{path}` (تتطلب جلسة
  المالك) خلاف ذلك (بحد أقصى 16). المسارات العامة للقراءة فقط: `GET` أو
  `HEAD`. لا يجوز أن يكون أول مقطع في المسار `install` أو `enable` أو
  `disable` أو `remove`.

## مسار اعتماد المالك

لا يُنفَّذ شيء قبل الاعتماد. من صفحة **الإضافات** في لوحة التحكم
(`‎/{locale}/admin/plugins`)، المدعومة بمسارات API خاصة بالمالك تحت
`‎/api/v1/plugins`:

1. يظهر المجلد ذو البيان الصالح بحالة **جاهزة للتثبيت** مع محتوى بيانه.
   يسجّل زر **اعتماد وتثبيت** البيان وبصمة SHA-256 لكل ملف في SQLite،
   وتبقى الإضافة معطّلة.
2. يتحقق زر **تفعيل** من أن الملفات ما تزال مطابقة للبصمات المعتمدة، ويرفض
   أي استيراد لدالة مضيف لا يعلن البيان صلاحيتها، وعندها فقط يسجّل نقاط ربط
   الإضافة ومساراتها. يفرّغ زر **تعطيل** الإضافة فورًا؛ الإضافة المعطّلة لا
   تعمل أبدًا.
3. أي تغيير في ملف على القرص ينقل الإضافة إلى حالة **تغيّرت الملفات منذ
   الاعتماد**: لن تُحمَّل مجددًا حتى يعيد المالك اعتمادها، وتعرض الصفحة
   البيان الجديد مع إبراز الصلاحيات المضافة.
4. يحذف زر **إزالة** سجل الاعتماد، ومن خلال المخطط بياناتِ الإضافة المخزنة.
   تبقى الملفات داخل `plugins/` على القرص للمشغّل.

يتطلب التثبيت والتفعيل والتعطيل والإزالة إعادة مصادقة حديثة، يُعاد التحقق
منها داخل معاملة التعديل نفسها، تمامًا مثل بقية عمليات المالك الحساسة. تستخدم
كل السجلات إصدارات تفاؤلية (`expected_version`).

## العزل والحدود

تُنشأ الوحدات لكل استدعاء على حدة عبر wazero (بلغة Go صرفة، دون cgo):

- لا مجلدات مفتوحة مسبقًا، ولا مقابس شبكة، ولا متغيرات بيئة؛ التأثيرات
  الوحيدة تمر عبر دوال المضيف المرقّمة `modawana_v1`.
- لكل استدعاء: 5 ثوانٍ، و64 ميبيبايت من الذاكرة الخطية، و64 كيبيبايت لنتيجة
  نقطة الربط، و256 كيبيبايت لمتن المسار، وبوابة تزامن صغيرة لكل إضافة.
- حمولات نقاط الربط ونتائجها هي نفس بايتات JSON المحدودة التي تتبادلها
  السجلات المدمجة؛ يُسجَّل فشل نقطة الربط ويُهمل، ولا يفشل الطلب بسببه أبدًا.
- يتحقق المضيف من استجابات المسارات: الحالة بين 200 و599، والنوع
  `application/json` أو `text/plain` فقط.

## التخزين

توفر صلاحية `storage` مخزن مفاتيح وقيم ومجموعات مستندات JSON ذات نطاقات
معزولة في جداول SQLite يملكها المضيف (`plugin_kv` و`plugin_documents`)،
مفتاحها سجل التثبيت بحيث لا تستطيع إضافة قراءة بيانات غيرها أبدًا. حصص
المرحلة 1 لكل إضافة: 1024 مفتاحًا و1 ميبيبايت من بيانات المفاتيح والقيم
(القيمة بحد أقصى 64 كيبيبايت)؛ و4096 مستندًا و4 ميبيبايت من بيانات المستندات
(المتن بحد أقصى 256 كيبيبايت من JSON صالح). تأتي ترحيلات قاعدة البيانات التي
تعلنها الإضافة في المرحلة 2.

## عقد الاستدعاء

تعمل الوحدة كأمر WASI: مظروف JSON واحد على الإدخال القياسي، والنتيجة على
الإخراج القياسي، ورمز خروج 0. مظروف نقطة الربط هو
`{"api":1,"kind":"hook","hook":"…","hook_version":1,"payload":…}` والإخراج
هو نتيجة نقطة الربط الخام. ومظروف المسار هو
`{"api":1,"kind":"route","method":"GET","path":"/hello","query":{…},"owner":false,"body":"…"}`
والإخراج هو `{"status":200,"content_type":"application/json","body":"…"}`.

الإضافة المثال الأصلية في
[`backend/internal/plugin/testdata/example`](../backend/internal/plugin/testdata/example/main.go)
هي التنفيذ المرجعي؛ اختبارات التكامل تجمّعها وتشغّلها. ابنِها بالأمر:

```sh
node scripts/build-example-plugin.mjs
```

## حدود المرحلة 1

- تُرفض الصلاحيات خارج `hooks` و`routes` و`storage`.
- مسارات الإضافات العامة للقراءة فقط (`GET`/`HEAD`)؛ وتُحسب بصمات الملفات
  الثابتة دون تقديمها.
- لا ترحيلات تعلنها الإضافة، ولا عرض لمخطط الإعدادات، ولا مهام مجدولة، ولا
  HTTP صادر، ولا أسرار، ولا كشف لأدوات MCP.
- لا تحقق من التوقيعات: التثبيت فعل صريح من المالك مع تثبيت البصمات، ولا
  يستطيع وضع ملفات الإضافات غير المشغّل.

# عقود HTTP والإعدادات

[English](README.md) · [التوثيق](../README.ar.md) · [OpenAPI v1](v1.openapi.json)

تغطي API من الأصل نفسه المصادقة والأمان والمحتوى والوسائط والإعدادات والتعلم والنشر المحدد الصلاحيات. تبقى الموارد الخاصة كذلك بصرف النظر عن موجّه الواجهة. أبق OpenAPI وfrontend/src/api/contracts.ts متوافقين مع تحقق Go.

| المسار | السلوك |
| --- | --- |
| GET/HEAD /healthz | الحياة؛ 200 مع `{"status":"ok"}` |
| GET/HEAD /readyz | 200 عند جاهزية الاعتماديات بفحص محدود، وإلا 503 |
| GET/HEAD /api/v1/public/runtime | قائمة عامة صريحة: api_version وdefault_locale وlocales |
| GET/HEAD /assets/{hashed-name} | الملفات الثابتة المسجلة حصراً في بيان البناء المتحقق منه |
| GET/HEAD /, /en, /ar, /fr | هيكل HTML مهرب من Go يحمل React مع lang/dir محليين |
| API/وسائط/أصل مفقود | JSON 404، دون نجاح HTML |
| صفحة غير معروفة | HTML 404 مع noindex |

لا تُصدر سماحية CORS. تستخدم طلبات المتصفح مسارات نسبية. تستخدم JSON والأخطاء وHTML سياسة no-store، وأصول البناء الناجحة تخزيناً ثابتاً لعام. يقدم Go الإنتاج دون عملية Node. nonce للسكربت جديد لكل استجابة؛ تمنع CSP السكربتات الخارجية والتضمين والكائنات والأنماط المضمنة دون nonce. يقبل BrandStyle قيمة nonce الخاصة بالاستجابة من عنصر meta، ولا تحتاج الألوان الافتراضية ورقة تجاوز. يجب أن تحافظ الألوان الديناميكية مستقبلاً على nonce أو تستخدم مسار أنماط.

## الأخطاء والمدخلات المحدودة

الغلاف `{"error":{"code":"not_found","message":"Resource not found.","request_id":"…"}}`. تحمل fields الاختيارية أكواد تحقق آمنة، لا أسراراً مدخلة. الأكواد: 400 معطوب و401 غير مصادق و403 ممنوع و404 مفقود و405 طريقة و409 تعارض نسخة/تكرار و413 كبير و415 نوع محتوى و422 حقول و429 تقييد و500 داخلي و503 غير متاح. يضيف تقييد المصادقة Retry-After. الرسائل عامة وتربط الواجهة الأكواد بنصوص مترجمة.

يقبل DecodeJSON بنية محددة الأنواع وحد بايتات صريحاً لكل مسار. يشترط application/json ويرفض null والمصفوفات والحقول المجهولة وJSON اللاحق ويحد الجسم دون Content-Length أيضاً. لا تضاف نقطة تعديل لاختبار المحلل فقط. يولد الخادم معرّفات الطلب ويتجاهل الواردة. تسجل السجلات المعرّف والطريقة من قائمة مسموحة والحالة والمدة، ولا تسجل الأجسام أو cookies أو authorization أو URL/query الخام أو قيم الإعداد أو أخطاء المعالج الخام. يتطلب سجل الوكيل الحجب نفسه.

## إعداد المشغّل

تُقرأ الإعدادات من البيئة وليس تلقائياً من ملفات .env. تذكر الأخطاء اسم المتغير فقط، ولا يُضمّن متغير بيئة في بناء الواجهة.

| المتغير | القاعدة |
| --- | --- |
| BLOG_ENV | production افتراضياً أو development |
| BLOG_BASE_URL | origin دقيق دون شرطة ختامية/مسار/query/userinfo؛ HTTPS عدا HTTP للحلقة المحلية في التطوير |
| BLOG_RP_ID | اسم مضيف BLOG_BASE_URL نفسه دون توسيع إلى نطاق أب |
| BLOG_WEBAUTHN_ORIGINS | origin المضبوط نفسه بفواصل؛ لا يفتح أساس المصدر الواحد origins بديلة |
| BLOG_DATA_ROOT | مسار مطلق مطلوب خارج checkout والإصدار الجاري والواجهة؛ تُحل أسلاف الروابط الرمزية الموجودة؛ لا يُقدم هذا المجلد |
| BLOG_FRONTEND_DIST | يُفضل مطلقاً؛ الافتراضي ../frontend/dist نسبةً لمجلد العمل؛ البيان مطلوب في الإنتاج |
| BLOG_LISTEN_ADDR | IP:port صريح؛ الافتراضي 127.0.0.1:8080، وHTTPS الخارجي للوكيل |
| BLOG_TRUSTED_PROXIES | فارغ افتراضياً أو CIDRs لعناوين نظراء الوكيل الفعليين بفواصل |

يتجاهل IP العميل ترويسات التمرير من النظير غير الموثوق. للموثوق، يُحد ويُتحقق من X-Forwarded-For ويُفحص من اليمين إلى أول قفزة غير موثوقة. تعيد القائمة المعطوبة عنوان النظير المباشر. لا يحل المضيف أو البروتوكول الممرر محل origin أو RP ID المضبوطين. اضبط الوكيل لإحلال النظير الفعلي أو إلحاقه صحيحاً. يستخدم تقييد المصادقة هذا المحلل وحده لا الترويسات الخام. تنفذ خدمة المصادقة تحقق WebAuthn والأصل المطابق وCSRF.

يوفر أمر التطوير إعدادات الحلقة المحلية ومجلد بيانات مؤقتاً خاصاً بالنسخة ما لم يُضبط BLOG_DATA_ROOT. قد يحذف النظام بيانات التطوير المؤقتة؛ لا تُستخدم للإنتاج. بعد البناء، من جذر المستودع:

```sh
BLOG_ENV=production \
BLOG_BASE_URL=https://blog.example \
BLOG_RP_ID=blog.example \
BLOG_WEBAUTHN_ORIGINS=https://blog.example \
BLOG_DATA_ROOT=/var/lib/personal-blog \
BLOG_FRONTEND_DIST="$PWD/frontend/dist" \
./build/blog
```

استخدم مجلد بيانات خاصاً موجوداً قابلاً للكتابة يملكه حساب الخدمة. لإعداد VPS والترقية اتبع [دليل النشر](../../deploy/README.md). إعداد القاعدة وقواعد النسخ المطلوبة قبل الترحيل في [دليل SQLite](../../backend/migrations/README.ar.md).

## حد الصلاحيات المشترك والتحقق

يعرّف internal/access هوية وسطحاً ومورداً/لغة/طريقة وقرار رؤية محدد الأنواع للمحتوى والوسائط والمعاينة والبحث والتغذيات والمجموعات. يرفض القرار الصفري وDenyAll كل جمهور. لا يمنح PublicTeaser جسماً. تحل السياسة الحية حالة النشر والخطة النشطة باتساق للمحتوى والوسائط والبحث والمجموعات. لا يكفي URL أو مرجع وسائط منشور وحده. تبقى خطط الدروس المفقودة أو غير المدعومة مقفلة؛ توسع قواعد الاختبارات والمتعلم هذا الحد لاحقاً.

شغّل `go test ./...` و`go vet ./...` داخل backend/. تغطي الاختبارات حدود المدخلات والمسارات المفقودة وتزوير الوكيل وorigin والمسارات واجتياز الأصول وروابطها الرمزية وفشل الجاهزية وخلو الاستجابات والسجلات من الأسرار. بعد البناء وتثبيت Playwright، يبدأ `node scripts/smoke-production.mjs` ثنائي Go وحده ويفحص الواجهة وAPI والأصول على المصدر نفسه، ثم مصفوفة لغات ومظاهر المتصفح على الهيكل وCSP الحقيقيين. يستخدم مشغّل الاختبار Node وليس التطبيق المقدِّم.

# الناشر المحدود وأداة Go

[English](publisher.md) · [فهرس API](README.ar.md) · [مشغّل التسليم](../integrations/lesson-delivery.ar.md)

تنشئ صفحة أمان المالك رموزاً مسماة بصلاحيات مستقلة `draft` و`media` و`quiz`
و`publish`. اختر مفاتيح المجموعات؛ تحتاج المقالات خارج المجموعات إلى سماح صريح
إضافي. يتطلب الإنشاء توثيق دخول كامل خلال خمس دقائق ويُعاد فحصه داخل المعاملة.
تبدأ الواجهة بصلاحية المسودة فقط وانتهاء بعد 90 يوماً؛ تقبل الواجهة البرمجية
1–365 يوماً. الحد 50 رمزاً فعالاً غير ملغى أو منتهٍ. تُخزن بصمة SHA-256 فقط.
احفظ السر المعروض في مخزن أسرار المشغّل؛ لا تعيده القراءات اللاحقة. يمكن إعادة
تسمية الرمز أو إلغاؤه من صفحة الأمان.

المسار `/api/v1/security/publisher-tokens`: يسرد GET البيانات الوصفية، ويقبل
POST `{label,scopes,collections,allow_articles,days}` ويعيد البيانات مع `secret`
مرة واحدة، ويقبل PATCH `{id,label}` وDELETE `{id}`. تستخدم هذه المسارات جلسة
المالك وحدود Origin وCSRF المعتادة. لا تنشئ رموز النشر اعتمادات ولا تتحول إلى
جلسات مالك أو قارئ.

## مسارات الآلة

يستخدم النطاق `/api/v1/publisher/` الترويسة `Authorization: Bearer …` ولا يعتمد
ملفات ارتباط المتصفح. تُرفض معاملات الاستعلام. لا توضع الأسرار في الروابط أو
Markdown أو حزم الواجهة أو السجلات. تستدعي المسارات خدمات المحتوى والوسائط نفسها
مع فحص الإلغاء والصلاحيات وقيود المجموعات داخل معاملات التعديل.

| المسار | الصلاحية والسلوك |
| --- | --- |
| `GET /content/{key}/{locale}` | `draft`؛ قراءة المسودة الحالية المسموحة للمطابقة. تحتاج المسودة ذات الاختبار أيضاً إلى `quiz`. |
| `PUT /content/{key}/{locale}` | `draft`؛ JSON المسودة نفسه للمالك. تتطلب إضافة الاختبار أو تغييره أو حذفه `quiz`. |
| `POST /content/{key}/{locale}/publish` | `publish`؛ `{expected_version,revision_id}` محددان. تبقى مراجعة الترجمة وقيود التقييم النشط مفروضة. لا تطبيق لخطة مسار. |
| `POST /media` | `media`؛ جزء multipart واحد اسمه `file` ولغرض المحتوى فقط. يمكن ربط مرفوعات الرمز أو الوسائط المشار إليها سابقاً في مجموعة/مقال مسموح. |

المسارات نسبية إلى `/api/v1/publisher`. يتطلب كل تعديل `Idempotency-Key`؛ تعيد
الإعادة المطابقة النتيجة خلال سبعة أيام، وتعيد إعادة المفتاح بمحتوى مختلف 409.
تعيد تعارضات نسخ المسودة والنشر 409 أيضاً. طابق الحالة عبر GET قبل إعداد عملية
جديدة عمداً؛ لا ترفع النسخة المتوقعة تلقائياً بعد التعارض. يطبق الإلغاء حتى على
إعادة المحاولات.

لا تراجع الرموز الترجمات أو التقييمات ولا تعدل الشروط أو تطبق الخطط أو تعيد
التقدم أو تغير الهوية البصرية أو المصادقة أو تنتحل القارئ. لا يستطيع الرمز
استبدال تقييم خلف شرط نشط. يستطيع المالك مراجعة التقييم الجديد ونشره صراحة مع
خطة محفوظة مطابقة.

تتحكم `quiz` في الوصول إلى إجابات المسودات وتحرير الاختبارات؛ وتسمح `publish`
بصورة مستقلة بنشر مراجعة محفوظة محددة ضمن النطاق، بما فيها مراجعة تحتوي اختباراً.
لا يمنح النشر الوصول إلى الإجابات أو تحرير الاختبار أو سلطة المراجعة. تبقى
فحوص مراجعة الترجمة والتقييم المرتبط بالشرط النشط مفروضة.

## أداة الأوامر

ابنِ عبر `node scripts/project.mjs build`. يوفّر المشغّل `BLOG_URL` و
`BLOG_PUBLISHER_TOKEN` عبر بيئة الأسرار. يلزم HTTPS إلا لعنوان IP حلقي حرفي
في الاختبارات. يحدد `BLOG_PUBLISHER_CA` اختيارياً ملف PEM لشهادة موثوقة ولا يعطل
التحقق منها. لا تتبع الأداة إعادة التوجيه ولا تقبل الرمز كوسيط أمر.

```sh
build/publisher upload --file image.webp --mime image/webp --idempotency lesson-001-image
build/publisher draft --key lesson-001 --locale en --input draft.json --markdown lesson.md --idempotency lesson-001-draft
build/publisher get --key lesson-001 --locale en
build/publisher publish --key lesson-001 --locale en --revision SAVED_REVISION_ID --expected-version 1 --idempotency lesson-001-publish
```

يستخدم `draft.json` مخطط `DraftInput`: النسخة `expected_version` (0 للجديد)،
والنوع ولغة المصدر والرابط والعنوان والملخص الاختياري ومفتاح المجموعة والموضع
للدرس/الوثيقة والاختبار الاختياري ومراجع الوسائط ومراجعة المصدر للترجمة. يزوّد
`--markdown` الجسم من ملف مستقل. المخرجات JSON بمعرّفات مراجعات ثابتة ونسخ، أو
حالة/رمز خطأ API؛ تعني حالة خروج 1 الفشل. أعد العملية المنقطعة بالمحتوى والمفتاح
نفسيهما.

## مشغّل الناشر المحلي

احفظ القيم التالية فقط في `~/.config/personal-blog/publisher.env` خارج Git،
بصلاحية 0700 للمجلد و0600 للملف:

```sh
BLOG_URL=https://blog.example
BLOG_PUBLISHER_TOKEN='PASTE_YOUR_BLOG_TOKEN_HERE'
```

استبدل القيمة المؤقتة سراً. يحدد `BLOG_PUBLISHER_CA` اختيارياً ملف PEM موثوقاً.
لا تعرض هذا الملف أو متغيرات البيئة ولا تفعّل تتبع أوامر shell ولا تضع الرمز في
طلب النموذج أو وسيط أمر أو جدول. يقرأ مشغّل Node بيانات dotenv دون تنفيذ تعبيرات
shell، ويرفض الروابط الرمزية والملفات المتاحة للمجموعة أو الآخرين أو المملوكة
لمستخدم آخر وأسماء الإعدادات غير المتوقعة، ثم يمرر الاعتمادات إلى ناشر Go عبر
بيئة العملية التابعة فقط. يقلل ذلك التسريب العرضي؛ ولا يحجب الملف عن الأدوات أو
المستخدمين الذين يملكون وصولاً إلى نظام الملفات أصلاً.

ابنِ الملف التنفيذي لـMac من جذر المستودع؛ لا تحتاج إلى إعادة بناء VPS:

```sh
cd backend
go build -trimpath -o ../build/publisher ./cmd/publisher
cd ..
node scripts/publish.mjs --check
```

يتحقق `--check` من الإعداد المحلي وتوفر الملف التنفيذي دون طلب شبكة. لا يثبت
صحة الرمز أو صلاحياته أو تاريخ انتهائه. مرر وسائط الأداة المعتادة إلى
`node scripts/publish.mjs`، مثلاً:

```sh
node scripts/publish.mjs get --key EXISTING_CONTENT_KEY --locale en
node scripts/publish.mjs draft --key lesson-001 --locale en --input draft.json --markdown lesson.md --idempotency lesson-001-draft
```

جهّز البيانات الوصفية وMarkdown الموثقين أولاً لإنشاء مسودة فعلية، واحتفظ بالمدخل
ومفتاح الإعادة نفسيهما عند المحاولة مجدداً. ابدأ بقراءة عنصر مسموح موجود إن توفر.
لا تستخدم مفتاح محتوى غير موجود لاختبار المصادقة: تُفحص الصلاحيات قبل البحث عن
المسودة وقد تعيد 403 بدلاً من 404. يعيد الرمز غير الصحيح أو المنتهي أو الملغى
401. لا تثبت 403 السماح بكل الصلاحيات أو المجموعات المطلوبة.

لاختبار مسودة خاصة مقصودة، يحتاج الرمز صلاحية `draft` والسماح بالمقالات خارج
المجموعات. لا تُستورد ملفات الاختبار هذه تلقائياً مطلقاً:

```sh
node scripts/publish.mjs draft --key publisher-connection-check --locale en --input scripts/fixtures/publisher-check.json --markdown scripts/fixtures/publisher-check.txt --idempotency publisher-connection-check-v1
node scripts/publish.mjs get --key publisher-connection-check --locale en
```

ينشئ ذلك مقالة اختبار واحدة غير منشورة، وليس منشوراً عاماً. تعيد محاولة الأمر
المطابق استخدام مفتاح الإعادة نفسه. توقف عند تعارض النسخة؛ لا تستبدل عنصراً
موجوداً أو ترفع النسخ تلقائياً. افحص المسودة ضمن مقالات المالك. يختبر ذلك صلاحية
مسودة المقالة لا صلاحيات الوسائط أو الاختبار أو النشر أو مسار التعلم.

يتطلب النشر معرّف المراجعة والنسخة المحفوظين وطلب نشر مأذوناً أو سياسة دروس
مهيأة للغة الأصلية؛ لا تعني صلاحية الرمز وحدها الإذن بنشر نص عشوائي. تبقى صلاحيات
المجموعات ومراجعة المالك للترجمات والتقييمات وشروط الدروس مفروضة.

لا تستطيع مهمة آلية محلية استدعاء المشغّل إلا إذا سمحت صلاحيات الملفات والشبكة
بقراءة الإعداد الخاص وتشغيل الناشر والوصول إلى أصل HTTPS. لا ينتقل الاعتماد
المحفوظ تلقائياً إلى محادثة أخرى أو مشغّل سحابي أو درس مجدول. ليس هذا المشغّل
خادم MCP. راجع [نقطة تحقق التسليم](../integrations/lesson-delivery.ar.md) قبل تعديل
الجداول الحالية. افحص التعامل مع الاعتمادات عبر
`node --test scripts/publish.test.mjs`.

التحقق: تغطي اختبارات Go حداثة المصادقة والبصمات وعزل المجموعات والاختبارات
والإلغاء والتعارض والإعادة ومحاولات توسيع الصلاحيات. تفحص مجموعة المتصفح بالخادم
الحقيقي واجهة الرموز باللغات الثلاث وأداة Go الفعلية لإعادة الرفع والمسودة
والنشر المحدد والإلغاء. لا تُزرع اعتمادات أو بيانات إنتاج.

## النشر البعيد وإعداد المشغل

استخدم [MCP/OAuth](../integrations/mcp-oauth.md) للعملاء البعيدين المدعومين
و[المجدول](../integrations/remote-publishing.md) للدروس المولدة اختيارياً.
كلاهما يعيد استخدام صلاحيات الناشر؛ اعتمادات التوليد منفصلة.

المسار الافتراضي للمشغل هو `~/.config/personal-blog/publisher.env`. يمكن للتثبيتات
الحالية الاحتفاظ بملفها الخاص بضبط `BLOG_PUBLISHER_CONFIG` إلى مساره المطلق قبل
تشغيل المشغل. لا تُنقل الاعتمادات تلقائياً.

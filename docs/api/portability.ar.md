# نقل محتوى المالك

[English](portability.md) · [فهرس API](README.ar.md)

افتح **الاستيراد والتصدير** من تنقل المالك. تتطلب العمليتان جلسة مالك كاملة
وOrigin وCSRF مطابقين ومصادقة خلال خمس دقائق. لا تستطيع رموز الناشر المحدودة
تصدير السجل الخاص والإجابات أو استيراد تثبيت. يُعاد فحص الجلسة داخل معاملة اعتماد
الاستيراد.

- `POST /api/v1/portability/export`: تنزيل `application/zip` دون جسم طلب.
- `POST /api/v1/portability/import`: جسم ZIP مباشر؛ يعيد أعداد المراجعات والوسائط
  والمجموعات و`review_required:true`. يُدعم الهدف الخالي من المحتوى والإعدادات
  فقط، وتبقى تهيئة المالك وأمانه. يعيد الهدف غير الفارغ 409 والحزمة غير الصالحة
  422 أو خطأ تحقق المجال المناسب.
- نقل واحد في الوقت نفسه (429 عند الانشغال)، ومهل HTTP خمس دقائق. حد رفع
  المتصفح 256 MiB. تُعاد التنزيلات المنقطعة.

الأوامر المحلية المكافئة (مسارات مطلقة؛ يجب ألا يوجد ملف الخرج):

```sh
build/blog export --file /private/content.zip
build/blog import --file /private/content.zip
```

تحتوي الحزمة `manifest.json` بإصدار 1 والبصمات والأحجام و`data.json` وملفات
Markdown المختارة (يختار المصدّر **كل المراجعات المحفوظة**) والوسائط المرتبطة.
تُحفظ مؤشرات المراجعات الحالية وروابط الترجمات بالمصدر عبر إعادة ربط المعرّفات.
تشمل الاختبارات الإجابات الخاصة، لذا احفظ الحزمة كبيانات خاصة بالمالك. تشمل
الإعدادات والنصوص المطبقة والتصنيفات ولغات المجموعات وخطط المسودات والشروط
المقصودة. تُستبعد الاعتمادات والجلسات وهويات القراء وتقدمهم والرموز وإعدادات
المشغّل وسجلات الأمان ومراجعات الإعدادات. هذه ليست نسخة تعافٍ كاملة.

الحدود: 20,000 عنصر أرشيف و2 GiB إجمالي استخراج و256 MiB للملف و8 MiB لبيان
JSON وبياناته و2,000 مراجعة محتوى و10,000 وسيط و1,000 مجموعة و3,000 صف تصنيف
محلي. تبقى قواعد تحقق المحتوى والوسائط نافذة. تُرفض المخططات غير المدعومة
والتكرارات والروابط الرمزية والمسارات غير الآمنة والمراجع المفقودة والاختبارات
غير الصالحة واختلاف البصمات. تُفحص الأحجام أثناء التدفق، ويُستخرج الأرشيف في
مساحة مؤقتة خاصة فقط. لا يُنفذ SQL من الأرشيف.

يعيد الاستيراد بناء تثبيت مرحلي منفصل عبر أدوات التحقق المعتادة. تُولد معرّفات
ومسارات جديدة وتُربط مراجعات المصدر والاختبارات والوسائط بها. بعد اكتمال التحقق
فقط تُثبت الملفات وتُعتمد البيانات معاً في الوجهة التي ما زالت فارغة. قد يترك
فشل الاعتماد ملفات مولّدة بلا مرجع؛ تجمع الصيانة المحدودة الملفات اليتيمة القديمة.
لا يُنشر محتوى مستورد ولا تنشط خطة مجموعة ولا تُنسخ مراجعة ترجمة أو تقييم.
تبدأ المجموعات غير ظاهرة. راجع الاختبارات والشروط وانشر المراجعات المقصودة ثم
طبّق الخطط. تُحفظ الإعدادات كسجل غير مطبق: افتح الإعدادات أو الملف أو النصوص،
واستعد المراجعة إلى المحرر وراجع الترجمات ثم طبّق صراحة. يجب نشر مستند About قبل
تطبيق ملف يشير إليه.

## تصدير Markdown من Notion ‏(041)

يقبل قسم **الاستيراد من Notion** ملف ZIP الأصلي بصيغة **Markdown & CSV** مع
الصفحات الفرعية. وهو منفصل عن مستورد أرشيف المدونة أعلاه، ويضيف مسودات إلى تثبيت
موجود دون تغيير إعداداته. اختر لغة المحتوى EN/AR/FR (لا ترجمة تلقائية)، ثم
**مقالات** أو **مسار تعلم مرتب**. عاين الصفحات قبل **استيراد هذه المسودات**.
تربط النتيجة بقائمة المحتوى للمراجعة والنشر.

- `POST /api/v1/portability/notion/preview?locale=en&kind=article`
- `POST /api/v1/portability/notion/import?locale=en&kind=learning`

يستخدم الأمران جسم ZIP خاماً وحدود المالك وCSRF والمصادقة الحديثة وحجم الرفع
والتزامن والمهلة نفسها للنقل الأصلي. يُقبل `locale` و`kind` فقط، مرة لكل منهما.
تعيد المعاينة `pages` و`issues` و`media` المرتبطة وملفات `ignored` وصفحات `skipped`
الموجودة و`collection_title` المقترح. يعيد الاستيراد العدادات المعتادة
و`review_required` و`skipped`. تعني 409 ظهور صفحة أو مسار أو مجموعة متعارضة، أو أن
المتابعة ستغير مسار تعلم موجوداً؛ لا يُستبدل شيء.

يأتي عنوان الصفحة من H1 الأول (يُحذف من الجسم لتجنب تكرار عنوان القارئ)، وإلا من
اسم الملف دون معرّف Notion. تستخدم الهوية الثابتة معرّف الصفحة ولغتها المختارة،
أو مسارها النسبي في الأرشيف عند غياب المعرّف. تتجاوز الإعادة الهويات الموجودة
وتحفظ تعديلات المالك. تُعاد كتابة روابط Markdown الداخلية إلى روابط الموقع
المستقبلية والمرفقات المرتبطة إلى وسائط مدارة خاصة؛ وتبقى أمثلة الشيفرة كما هي.
لا تُجلب صور أو موارد خارجية، ولا تتحول ملفات CSV والأصول غير المرتبطة إلى
مقالات أو جداول قواعد بيانات.

ينشئ وضع التعلم مجموعة مخفية واحدة وخطة مسودة. تبقى صفحة النظرة العامة الوحيدة
في الجذر، المتبوعة بصفحات متداخلة، مقالاً، وتصبح الصفحات التابعة دروساً. تصبح
التصديرات الأخرى مجموعة واحدة من الدروس. تُرتب الملفات الشقيقة المرقمة طبيعياً
(`20` ثم `20A` ثم `20B` ثم `21`) بصرف النظر عن ترتيب ZIP. لا تُستنتج اختبارات
أو مفاتيح إجابات أو شروط إكمال أو بوابات من نص الدروس. انشر المسودات المختارة
وأظهر المجموعة وطبّق خطتها صراحة بعد المراجعة. هذه أداة نقل أولي، وليست مزامنة
مستمرة مع Notion؛ ولا توسّع خطة مسار تعلم موجودة أو تستبدلها.

الحدود: 20,000 عنصر ZIP و128 MiB لحجم الملفات غير المضغوط المعلن و50 MiB للملف
و1 MiB لصفحة Markdown و2,000 صفحة مقالات أو500 صفحة في وضع التعلم. تبقى فحوص
الوسائط والترميزات والأحجام والبكسلات المعتادة مطبقة. تُرفض المسارات المطلقة
واجتياز المجلدات والشرطة العكسية والعناصر والهويات المكررة والروابط الرمزية
وUTF-8 غير السليم والعناصر التالفة. يمنع HTML غير المدعوم (ومن ذلك HTML لتلميحات
Notion) والصور الخارجية والوسائط غير الصالحة والروابط المحلية المفقودة الاستيراد،
وتُعرض في المعاينة بدلاً من إسقاطها بصمت. الوسائط المدعومة JPEG وPNG وWebP
وMP4/WebM المتحقق منهما وPDF وVTT وفق قواعد الرفع المعتادة.

تُفحص الوسائط والمسودات كلها في قاعدة مرحلية معزولة قبل اعتماد البيانات الوصفية
ذرياً. يُعاد فحص صلاحية المالك وتعارض المفاتيح والمسارات داخل المعاملة. تُثبت
الملفات أولاً؛ وقد يترك فشل الاعتماد ملفات يتيمة للصيانة، ولا يترك صفحة عامة
مستوردة جزئياً. تُحفظ حماية المالك والمحتوى والهوية والتسميات وتقدم القراء والخطط
النشطة الموجودة. تبقى المسودات والوسائط المستوردة خاصة حتى يسمح النشر المراجع
المعتاد بالوصول.

# API المحتوى والاكتشاف والمجموعات

[English](content.md) · [فهرس API](README.ar.md) · [OpenAPI](v1.openapi.json)

تدعم خدمات المحتوى القراءة والتحرير وشروط الاختبارات
و[واجهة الناشر المحدودة وأداة CLI](publisher.ar.md) المنفصلتين. لا يُزرع محتوى. نفّذ [تهيئة المالك](../owner-security.ar.md)
أولاً. تتطلب المسارات الخاصة جلسة مالك كاملة؛ وتتطلب الكتابة Origin مطابقاً
و`X-CSRF-Token`. لا تسمح ارتباطات الاسترداد والتسجيل أو رموز bearer بهذه المسارات.

كل المسارات أدناه نسبية إلى `/api/v1`. JSON محدود والحقول المجهولة مرفوضة
والاستجابات `no-store`. لا يحتوي المحتوى العام سجل مراجعات خاصاً أو مسار تخزين
أو اسم ملف مرفوع أصلياً. تشير حقول `url` العامة حالياً إلى موارد API؛ راجع [المسارات العامة](../public-pages.ar.md) لقارئ HTML.

## المسودات والسجل

| الطريقة/المسار | العقد |
| --- | --- |
| GET /content?cursor=… | قائمة عناصر خاصة حتى 50 بترتيب المفتاح الثابت |
| GET /content/{key}/{locale} | المسودة الحالية والنسخة ومعرّف المنشور وحالة مراجعة الترجمة وتقادمها |
| PUT /content/{key}/{locale} | لقطة مسودة جديدة كاملة؛ 201 للغة جديدة وإلا 200 |
| GET /content/{key}/{locale}/revisions?cursor=… | سجل خاص؛ الأحدث بالتوقيت والمعرّف أولاً، حتى 50 |
| GET /content/{key}/{locale}/revisions/{revision_id} | مستند تاريخي ثابت وخاص |
| POST /content/{key}/{locale}/restore | نسخ مراجعة إلى مسودة جديدة دون تغيير مؤشر المنشور |

يتطلب الحفظ `expected_version` و`kind` و`source_locale` و`slug` و`title` و`markdown`.
الحقول الاختيارية: `summary` و`source_revision_id` و`category_key` و`tag_keys`
و`cover_media_id` و`media_presentations` و`collection_key` و`position`.
تستخدم النسخة 0 لإنشاء نسخة لغة جديدة فقط. المفاتيح الثابتة حروف ASCII صغيرة
وأرقام و`_` و`-`، حتى 120 حرفاً، وتبدأ بحرف أو رقم. تثبت لغة المصدر عند الإنشاء، ويتغير النوع (`article` أو
`lesson` أو `doc`) بإجراء تحويل المالك الصريح فقط. يسمح slug بحروف وأرقام Unicode
و`_` و`-` حتى 160 حرفاً ويثبت بعد أول نشر حتى بعد إيقافه.

الحدود: Markdown بترميز UTF-8 حتى 1 MiB، عنوان 200 حرف وملخص 500 حرف وتصنيف
اختياري واحد وثمانية وسوم مختلفة. يحلل Goldmark المراجع بما فيها صيغة مراجع
Markdown؛ تُرفض HTML الخام وبروتوكولات الروابط غير الآمنة والصور الخارجية
والمرفقات النسبية غير المحلولة وروابط `/media/{id}` المعطوبة. تبقى روابط
HTTP(S)/mailto والجذر والأجزاء الداخلية روابط. يجب أن تكون الوسائط موجودة.
تحدد عروض الفيديو `media_id` و`poster_media_id` و`caption_track_media_id`
الاختياريين و`caption` (2000 حرف) و`transcript` (20000). يجب أن تكون الأغلفة
والملصقات صوراً والمسارات ملفات ترجمة. كل الوسائط المساعدة مراجع محفوظة تتبع
قواعد وصول المحتوى الأب.

يكتب كل حفظ ملفاً جديداً دائماً، حتى لتغيير الوصف فقط، ثم يعتمد مؤشر المسودة
والمراجع. النسخة المتوقعة القديمة تعيد 409. يسجل `Idempotency-Key` الاختياري
(1–128 حرف ASCII أو رقم أو `._:-`) النتيجة ذرياً لسبعة أيام: تعيد العملية
والحمولة المطابقتان النتيجة، وتعيد الحمولة المختلفة 409 `idempotency_conflict`.
لا تدخل نسخة الجسم إلى SQLite. بعد انتهاء المدة تبقى حماية النسخ من الاستبدال
الأعمى. يتطلب الناشر الآلي هذا الرأس في مسارات النشر المحدودة المنفصلة.

تستخدم الاستعادة `{expected_version,revision_id}` وتحفظ الوسائط والتصنيف.
تنسخ ارتباط المصدر القديم دون وراثة مراجعة الترجمة. يبقى slug المنشور ثابتاً
حتى عند استعادة مراجعة لها slug مسودة أقدم. الملفات التاريخية ثابتة؛ لا تعدلها مباشرة.

## المراجعة والنشر

يتطلب `POST /content/{key}/{locale}/publish` الحقول
`{expected_version,revision_id}` للمسودة الحالية المحددة. يفحص بصمة Markdown
وكل الوسائط قبل تغيير مؤشر المنشور. يستخدم `unpublish` الحقول نفسها للمراجعة
المنشورة الحالية ويحفظ السجل. يبقى إيقاف النشر ممكناً حتى مع تلف بيانات المحتوى.
يدعم كلاهما مفاتيح إعادة المحاولة.

تسجل الترجمة مراجعة بلغة مصدر العنصر نفسه. قبل نشر ترجمة جديدة يستدعي المالك
`review` بالحقول `{expected_version,revision_id,source_revision_id}`.
يجب أن يكون المصدر منشوراً حالياً ومطابقاً للمصدر المسجل في الترجمة. تزيد المراجعة
النسخة؛ استخدم العدد المعاد للنشر. يميز تغيير المصدر المنشور الترجمة الحية القديمة
بالتقادم دون حذفها؛ لا يمكن نشر ترجمة جديدة قديمة أو غير مراجعة. يمنع سحب المصدر
النشر الجديد أيضاً. تنفذ نقاط ربط الخدمة داخل المعاملة لسياسات الاختبارات والمسارات لاحقاً.

- يعيد `GET /public/content/{locale}/{slug}` المراجعة المنشورة الحالية فقط.
  المجهول وغير المنشور 404. الدرس المقفل 403 `lesson_locked` مع `teaser` آمن
  دون Markdown أو بيان وسائط أو بيانات عرض محمية.
- يعرض `GET /public/alternatives/{key}` اختيارات اللغة وslug ورابط API المنشورة
  فقط. تحتوي استجابة المحتوى البدائل نفسها؛ لا استبدال لغة ضمنياً.
- ترى الطلبات الجديدة النشر وإيقافه فوراً؛ لا يمكن سحب استجابة متصفح أو ملف سبق تنزيله.

## التصنيف والاكتشاف

يقبل `PUT /taxonomy/{category|tag}/{key}/{locale}` الحقول
`{expected_version,label,slug}`. تبقى المعرّفات والمفاتيح ثابتة والنسخة مشتركة
بين اللغات. حد الاسم 120 حرفاً والمفتاح 80 وslug عدد 160، ولكل نوع حد 500 مصطلح.
تطبق تعديلات أسماء التصنيف المشتركة فوراً؛ تتغير عضوية المراجعة العامة عند النشر فقط.
تشمل `GET /taxonomy?locale=en` المصطلحات الخاصة؛ لا تشمل
`/public/taxonomy?locale=en` إلا المستخدمة في منشورات اللغة مع أعداد المنشور.

يقبل `GET /public/content` و`/public/search` اللغة `locale` المطلوبة، واختيارياً
`kind` وslug التصنيف المترجم في `category` وslug الوسم المترجم في `tag`
و`q` و`limit` و`cursor`. تُدمج المرشحات بمنطق AND. البحث عن جزء نصي حرفي
في العنوان والملخص حتى 200 حرف؛ تحويل SQLite الافتراضي إلى الحروف الصغيرة
خاص بـASCII، دون اشتقاق كلمات أو بحث في الأجسام. حجم الصفحة 20 افتراضياً وحتى
50. الترتيب بالتوقيت المنشور تنازلياً ثم معرّف نسخة اللغة الثابت؛ يرتبط المؤشر
المبهم بالمرشحات وحجم الصفحة. لا تُعد اللغات غير المنشورة. قد تظهر الدروس المنشورة
كملخصات مقفلة. تقرأ كل صفحة الحالة الحالية؛ لا تمثل لقطة ثابتة عبر تغير النشر بين الطلبات.

## المجموعات والخطط النشطة

| الطريقة/المسار | العقد |
| --- | --- |
| GET /collections?cursor=… | قائمة مجموعات خاصة حتى 50 |
| GET /collections/{key} | اللغات والنسخة الحالية ومعرّفا خطة المسودة والنشطة وأعضاؤهما |
| PUT /collections/{key}/{locale} | `{expected_version,kind,slug,title,summary,visible}`؛ النوع learning/docs |
| PUT /collections/{key}/plan | `{expected_version,members:[{key,announcements:{en:"Explicit title"}}]}` |
| POST /collections/{key}/apply | `{expected_version,plan_id}`؛ خطة المسودة الحالية المحددة |
| GET /public/collections/{locale}/{slug} | اللغة المرئية والخطة النشطة بعناصر منشورة أو معلنة صراحةً فقط |

تحتوي المجموعة حتى 500 عضو. الدروس لمسارات التعلّم والوثائق للأدلة والمقالات
لأي منهما لا تنتمي. يُعيّن العنصر مرة وتُرفض النقلات بين المجموعات.
يمكن لـ`collection_key` و`position` في المسودة تعيين العضوية (موضع 1–500)،
ويزيد ذلك نسخة المجموعة أيضاً. يجب تطابق الموضع الموجود؛ تستخدم نقطة الخطة
لإعادة الترتيب. يحدد ترتيب المصفوفة المواضع الفريدة. لا يغيّر حفظ الخطة ترتيباً
أو إعلاناً عاماً؛ يبدل التطبيق المؤشر النشط والمواضع ذرياً بعد فحص نسخة المجموعة
المشتركة. لا تُحذف العضوية المنشورة وتبقى روابط المجموعة والعناصر ثابتة.

توفر `announcements` عناوين عامة صريحة لكل لغة. يبقى المحذوف مخفياً دون نسخ
عنوان مسودة أو عددها. يمكن ظهور مجموعة تحتوي إعلانات فقط وفق توسعة الملحق
الصريحة لخارطة الدروس القادمة. لا يحتوي عنصر Soon مفتاحاً أو slug أو URL؛
يبقى مسار محتواه 404. تعد المواضع العامة العناصر المرئية فقط وتخفي الفجوات الخاصة.
لا تمثل `published_count` و`announced_count` و`total` إنجاز القارئ.
تعيد اللغات المعطلة أو المفقودة والمجموعات العامة الفارغة 404.

تتطلب أجسام الدروس العضوية في الخطة النشطة. تستخدم الخطط المفتوحة
`gate_policy_version=0`، وتستخدم شروط الاختبارات المراجعة الإصدار 1 وتشترط كل
الحدود السابقة ذات الصلة في جيل التقدم الحالي. تمنع الخطط المفقودة والسياسات
غير المدعومة الوصول. لا ينقل الترتيب درساً قبل متطلب محفوظ بصمت. يمكن لنشر
تقييم بوابة جديد تطبيق خطته المراجعة المطابقة ذرياً؛ وإعادة الجيل إجراء مستقل
بمصادقة مالك حديثة. انظر [التعلم](learning.ar.md) لقواعد الوصول المشتركة للمحتوى
والوسائط والبحث والمجموعات.

## التحقق

تتحقق `go -C backend test ./...` و`go -C backend test -race ./...`
و`go -C backend vet ./...` و`node scripts/project.mjs check` من حدود المجال
والتخزين والصلاحيات والتعارضات. يستخدم `scripts/smoke-content.mjs` المستدعى من
`smoke-auth.mjs` جلسة مالك HTTPS حقيقية وخادم Go وSQLite وملفات مؤقتة لتدفق
الرفع ثم المسودة والإعادة ثم المراجعة والنشر والبحث العام وإيقاف النشر وخطة المجموعة
وإعلاناتها. لا يُنشأ محتوى أو بيانات اعتماد للإنتاج.

## دمج الصفحات العامة

يضيف الاستكشاف الرابط الأساسي `url` و`category_key` و`tag_keys` و`reading_minutes` الاختياري. تشير روابط البدائل وعناصر المجموعات الآن إلى الصفحات العامة. تضيف المجموعات العامة رابطها الأساسي `url`؛ يُوثّق محلّل الصفحات وفهرس المجموعات المقسم في [الصفحات العامة](../public-pages.ar.md). تبقى نقاط JSON الحالية للمحتوى متاحة.

## النشر الجماعي

تعرض عناصر `GET /content?locale=en&kind=article&status=draft&q=…` الخاصة بالمالك
أيضاً `draft_revision_id` و`published_revision_id`، ويكون الأخير فارغاً لغير المنشور.
تتطلب `POST /content/bulk-publication` ملف جلسة المالك وOrigin وX-CSRF-Token الحالية.
حد الجسم 256 KiB مع رفض الحقول المجهولة:

```json
{
  "operation": "publish",
  "items": [
    {
      "key": "example-article",
      "locale": "en",
      "expected_version": 3,
      "revision_id": "0123456789abcdef0123456789abcdef"
    }
  ]
}
```

استخدم `publish` مع مراجعة المسودة المحفوظة المرصودة، أو `unpublish` مع مراجعة
النشر المرصودة، ومراجعة المسودة لعنصر غير منشور مسبقاً دون تغيير. تحتوي الدفعة
1–500 زوج مفتاح/لغة فريداً، وتلزم كل الإصدارات المتوقعة. تعيد الواجهة
`{changed, unchanged}`. تتحقق العناصر بلا تغيير من الإصدار والمراجعة دون زيادة
الإصدار. تشترك التغييرات في فحوص المحرر ضمن معاملة واحدة: يؤدي التعارض 409 أو فشل
القيم أو المراجعة أو الخطة 422 أو العنصر المفقود 404 أو أي خطأ آخر إلى التراجع
عن الجميع. تسري أخطاء المصادقة وCSRF الحالية. لا تُقبل بيانات مراجعة أو خطة أو
مراجعة تلقائية أو نجاح جزئي. لا تدعم الواجهة مفتاح تكرار العمليات: بعد فقد
استجابة، اقرأ الحالات الحالية قبل المحاولة بإصدارات محددة حديثاً.

لا تُحذف الملفات أو المراجعات أو المسودات ولا تُعاد كتابتها. لا حاجة لترحيل المخطط.
يعيد إلغاء النشر الحالة الحالية إلى مسودة غير عامة، ولا يمسح قفل الرابط بعد أول
نشر. تظل رؤية المحتوى في الاكتشاف والوسائط المحمية وحدود التعلم مشتقة من حالة
النشر والخطة المطبقة.

## التحويل الصريح للنوع

تظل لغة المصدر ثابتة، ويتغير النوع فقط بإجراء المالك الصريح وليس
بحفظ مسودة عادي. يتلقى POST `/content/{key}/{locale}/type` الحقول
`{expected_version, from_kind, kind, collection_key, expected_collection_version, position}`.
تتطلب الدروس والمستندات المجموعة وإصدارها والصفر للإلحاق بالعضوية الأولية. لا
تأخذ المقالة مجموعة أو ترتيباً. تعيد RevisionResult المراجعة نفسها بإصدار زائد؛
ويحدد Idempotency-Key الاختياري إعادة الطلب بالمالك والحمولة نفسها. تزيد إصدارات
اللغات معاً. تُرفض أعضاء الخطط الحالية والمستندات ذات الاختبارات الحالية ومستند
التعريف المختار برسالة `error.fields`. لا تتجاوز المسارات السابقة سياسة الوصول
والبوابات.

## تعديل النوع ومراجع المالك

يغير PUT لحفظ مسودة المالك النوع والنص ذرياً. لتغيير عنصر حالي إلى
درس أو مستند أرسل collection_key وexpected_collection_version وposition، والصفر
للإلحاق. تحفظ المعاملة النشر والسجل وتفحص الاعتمادات؛ يتراجع النوع والمسودة معاً
عند الفشل ويزيد إصدار كل لغة أخرى مرة. لا تعيد عمليات الناشر والاستيراد تصنيف
العناصر الحالية.

يعيد GET /owner/references?locale=en&kind=learning&q=… القيمة {items,more} بخمس
نتائج {key,title,kind,version} كحد أقصى. يدعم kind القيم learning/docs/lesson/doc
ويصفي collection_key الاختياري الأعضاء. تتطلب جلسة مالك واستجابة no-store وتبحث
في كل البيانات المطابقة باللغة المحددة دون رجوع نص المحتوى.

## تعيين الدرس والخطة الأولى

تعيد مسودة المالك collection_key وposition؛ تعيد المجموعة assigned_members مرتبة منفصلة عن draft_members. لا يعني التعيين وجود خطة. الترتيب 0 عند الحفظ يضيف غير المعيّن تلقائياً ويحفظ ترتيب المعيّن دون نقله. يحفظ المحرر خطة أولى خاصة عند الحاجة قبل النشر مع الخطة، ويستخدم معرّفها وإصدارها الناتجين. النشر والتفعيل ذريان؛ فشل الحفظ يمنع النشر. شروط الترجمة والظهور والبوابات تبقى كما هي.

## حفظ مجموعة مبسط

يحفظ PUT /collections/{key}/workspace?locale=en تفاصيل المجموعة وmembers [{key,announcements,expected_version?}] بمعاملة واحدة تشمل التحويل المحروس والخطة وتفعيلها دون نشر مسودات. إصدار المجموعة وفحوص المالك وOrigin وCSRF إلزامية؛ إصدار المقالة إلزامي للتحويل. يحمي Idempotency-Key الاختياري التكرار. أي فشل يتراجع بالجميع. يبقى API الخطة القديم متوافقاً. يضيف CollectionDocument قاموس member_titles الخاص بالمالك. يعرض نوع المراجع learning_item/docs_item المقالات والمحتوى المطابق غير المعيّن أو التابع للمجموعة الحالية، ويستبعد exclude_key المتكرر قبل حد النتائج الخمس.

## علامة إصدار البحث

يضيف /owner/references الترويسة X-Reference-Search-Version: 2 قبل فحص الجلسة. لا تتضمن بيانات خاصة. تميز الواجهة رد 422 الحالي عن خلفية قديمة لا تدعم أنواع البحث. غياب المسار يؤدي لإرشاد إعادة التشغيل؛ لا يغير ذلك المصادقة أو العقد الحالي.

## عناوين المالك وأسباب الحقول

يقبل GET /collections لغة locale اختيارية افتراضها en، ويعيد title مع key/kind/version. هذا رجوع خاص إلى الإنجليزية أو أول عنوان، ولا يغير محتوى اللغة العامة أو ترتيب cursor بالمفتاح. تعيد أخطاء المجموعة 422 مع fields آمنة: title/slug/key/locale/summary/members وأسباب collection_* المحددة، ومنها الرابط المكرر والعضوية الأجنبية وإزالة المنشور وترتيب المتطلبات ومراجعتها. لا تعاد القيم أو SQL. يبقى طلب slug صريحاً؛ التوليد من العنوان في واجهة المالك فقط.

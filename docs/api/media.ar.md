# API الوسائط بضوابط الوصول

[English](media.md) · [فهرس API](README.ar.md)

تدعم الخدمة رفع المالك وتقديم الملفات بضوابط وصول دون زرع بيانات تشغيل. تتطلب كل
كتابة متصفح جلسة مالك كاملة وأصل Origin مطابقاً و`X-CSRF-Token`؛ للنشر الآلي [واجهة محددة الصلاحيات](publisher.ar.md).

- `POST /api/v1/media?purpose=content`: multipart بجزء `file` واحد فقط.
  يعيد 201 و`{id,url,kind,mime_type,byte_size,filename,purpose,width,height,created_at}`.
  الرابط `/media/{id}`؛ تبقى المسارات والبصمات داخلية. الأغراض:
  `content` و`logo` و`favicon` و`portrait` و`banner`.
- `GET /api/v1/media?kind=image&cursor=…`: قائمة خاصة حتى 50 سجلاً مع
  `next_cursor`؛ التصفية اختيارية. المعرّفات عشوائية سداسية صغيرة الحروف.
- `DELETE /api/v1/media/{id}`: للمالك فقط؛ ترفض المراجع المحفوظة في المراجعات
  والإعدادات برمز 409. الاستبدال رفع جديد لا كتابة فوق الملف القديم.
- `GET/HEAD /media/{id}`: فحص الوصول قبل فتح البيانات ومعالجة Range. تعيد الوسائط
  غير المستخدمة أو الخاصة بمسودة 404 للعامة. يسمح مرجع إعداد عام مطبّق أو مراجعة
  منشورة يمكن للقارئ الوصول إليها بالقراءة. غياب سياسة شروط الدرس يمنع الوصول.
  تستخدم شروط التعلّم اللاحقة السياسة نفسها؛ لا مجلد رفع عاماً مباشراً.

تُفك صور JPEG/PNG/WebP بالكامل بعد فحص الأبعاد (حتى 24 مليون بكسل و8192 لكل محور)
وتُحدّ بـ10 MiB. الشعار وأيقونة الموقع: 1 MiB؛ الصورة الشخصية: 2 MiB ومربعة
و600×600 على الأقل؛ اللافتة: 10 MiB. تعيد الإعدادات فحص الغرض عند إعادة استخدام
معرّف ملف موجود.

الفيديو: حتى 50 MiB، مسار فيديو واحد حتى 4096×4096 ومسار صوت اختياري واحد.
يسمح MP4 بـH.264 (`avc1` مع SPS/PPS) وAAC-LC اختيارياً. يسمح WebM بـVP8/VP9
وOpus/Vorbis اختيارياً. تتحقق المكتبات من بيانات الحاوية وتركيبات الترميز المعلنة؛
لا تحويل ترميز ولا ضمان لفك إطارات تالفة عشوائياً. تتحقق عينات المتصفح من التشغيل
والانتقال فعلياً بصورة منفصلة. PDF: حتى 20 MiB مع فحص الرأس والمراجع ونهاية الملف،
ويُقدّم دائماً كمرفق مع CSP معزول وnosniff؛ ليس هذا فحص برمجيات خبيثة.
WebVTT بترميز UTF-8: حتى 1 MiB مع توقيت مقاطع صحيح ومحدود. تُرفض SVG والبيانات
التنفيذية وتعارضات النوع المعلن.

تستخدم الملفات مسارات خاصة مولّدة وfsync وإعادة تسمية على نظام الملفات نفسه قبل
تسجيل البيانات الوصفية، تحت قفل المراجعات والصيانة. لا تنتج الكتابة المنقطعة
مرجعاً حياً. يُحذف الملف بعد سجله؛ يبقى الملف اليتيم عند فشل الحذف للصيانة الصريحة.
تُفحص البصمة قبل التقديم. تستخدم الاستجابات `no-store`؛ يدعم نطاق بايت واحد محدود
الانتقال داخل الفيديو، وتعيد طلبات النطاقات المتعددة 416. لا يمكن سحب بيانات سبق تنزيلها.

التحقق: `go -C backend test ./internal/media ./internal/storage ./internal/http ./internal/db`.
يستدعي `scripts/smoke-auth.mjs` فحص `smoke-media.mjs` بجلسة مالك HTTPS حقيقية
وعينات MP4/WebM زرقاء مولّدة بحجم 32×32، دون بيانات مستخدم. يُشغّل بعد البناء
واختبارات الواجهة وتثبيت Playwright Chromium. لا تثبت هذه الاختبارات توافق Safari/Firefox؛ تحقق على الأجهزة المستهدفة.

# الاختبارات وشروط الفتح وتقدم المتصفح

[English](learning.md) · [فهرس API](README.ar.md) · [أدوات المالك](../owner-tools.ar.md)

## التأليف الثابت

يقبل `PUT /api/v1/content/{key}/{locale}` للمالك `quiz` اختيارياً:
`assessment_id` و`pass_mark` و`show_explanations` و`questions` التي تحوي
`id` و`type` (`single` أو`multi` أو`bool`) و`text` و`options:[{id,text}]`
و`correct:[optionID]` و`explanation`. يحذف الإغفال الاختبار من المسودة الجديدة
فقط. ترفض الوثائق الاختبارات. الإجابات الصحيحة حقول تأليف خاصة.

الحد 1–20 سؤالاً و2–8 خيارات ومعرّفات ثابتة فريدة تطابق
`[a-zA-Z0-9_-]{1,64}` وإجابة صحيحة واحدة للمفرد والمنطقي وواحدة أو أكثر للمتعدد.
خيارات المنطقي `true` ثم `false`. حدود السؤال والخيار والشرح 2000/1000/4000
نقطة Unicode؛ وحدا JSON الأصلي والمحلي 64/256 KiB. حد النجاح عدد صحيح من 1 إلى
عدد الأسئلة. لكل سؤال نقطة؛ يتطلب المتعدد تطابق المجموعة تماماً. تُرفض الإجابات
الناقصة والمكررة والمجهولة. المحاولات غير محدودة تعليمياً؛ حدود المعدل والتخزين
منفصلة.

تحفظ التقييمات الثابتة المعرّفات والإجابات وحد النجاح وسياسة الشرح. يرتبط النص
المحلي بمراجعة محتوى محددة. يجب أن تطابق الترجمة تقييم المصدر الحالي وتحصل على
مراجعة المالك المحددة قبل النشر. يمكن أن تبقى الأجسام المترجمة القديمة منشورة،
لكن اختباراتِها لا تمنح نجاحاً جديداً؛ تُعرض روابط اللغات المتاحة. لا تغيّر المسودة
الربط المنشور. تنشئ الاستعادة مراجعة تحتاج إلى مراجعة ترجمة جديدة.

تستخدم مسارات المالك التالية `/api/v1` وجلسة المالك وOrigin/CSRF للكتابة:

| المسار | العقد |
| --- | --- |
| `POST /content/{key}/{locale}/quiz-preview` | المسودة المحفوظة `{version:{quiz,content},answers,idempotencyKey}`؛ تصحيح خادم فقط دون هوية أو محاولة أو إنجاز. |
| `POST /content/{key}/{locale}/quiz-review` | يسجل `{expected_version,revision_id}` مراجعة التقييم المحدد. |
| `GET /content/{key}/{locale}/quiz-gate` | سياق المسودة `{key,version,plan_id,enabled}`. |
| `PUT /content/{key}/{locale}/quiz-gate` | ينسخ `{expected_version,plan_id,assessment_id,enabled}` حد مسودة مراجعاً. يقيّد الحد الأخير الدروس التي تُضاف مستقبلاً. |
| `POST /collections/{key}/apply` | خطة ونسخة محفوظتان محددتان؛ يتحقق من تقييم المصدر المنشور المراجع والترتيب الآمن. تبقى المتطلبات غير المتاحة مقفلة. |
| `POST /content/{key}/{locale}/publish` | ينشر `plan:{expected_version,plan_id}` الاختياري المصدر المشروط المعدل ويطبق خطته المطابقة ذرياً. تلغي الخطة القديمة النشر كله. |
| `POST /collections/{key}/progress-reset` | `{expected_version}`؛ توثيق كامل حديث للمالك يُفحص داخل المعاملة. يزيد الجيل ويحذف الإنجاز القديم ولا يحدث ضمن التعديلات العادية. |

تُحسب كل الشروط السابقة، لا الدرس السابق فقط. تحدد معرّفات دروس المصدر الثابتة
وجيل المسار النشط النجاحات. تحفظها التعديلات والترتيب المعتادان. لا يعبر هدف
متطلباً محفوظاً أثناء الترتيب؛ احذف الشرط صراحة أولاً إن كان تغيير السياسة مقصوداً.
لا يفقد المتطلب النشط تقييمه ولا يستبدله بصمت. لا يفتح إلغاء النشر شيئاً وتظل
النجاحات السابقة صالحة. يرى المالك المسار المتأثر قبل تغيير النشر/الخطة وتأكيداً
مستقلاً لإعادة التقدم.

## واجهات القارئ والخصوصية

- يعيد المحتوى المنشور المقفل 403 `lesson_locked` مع عنوان وملخص وروابط متطلب
  آمنة دون Markdown أو مراجع وسائط أو أسئلة. تعيد HTML المقفلة 403/noindex وغير
  المنشور 404. يحوي القادم الإعلان الصريح فقط. تستخدم GET/HEAD/Range للوسائط
  القرار نفسه بما فيها الملصقات والترجمة. يعرض البحث الملخصات فقط ولا تُحمّل
  الأجسام المحمية مسبقاً. يجعل الاستخدام في مرجع متاح آخر الوسيط متاحاً.
- يعيد `GET /api/v1/learning/content/{key}/{locale}/quiz` إسقاط `ReaderLearning`:
  `{version,quiz?,completed,can_mark_read,unavailable,alternatives,prerequisites}`.
  يحتوي `quiz` الأسئلة دون الإجابات والشروح. يتضمن المحتوى العام الإسقاط نفسه.
  تضم النسخة `quiz` و`content` وللدرس `path` و`epoch`.
- يقبل `POST .../attempts` الحقول
  `{version,answers:{questionID:[optionID]},idempotencyKey}`. يتحقق من الهوية
  والوصول والنسخ ويسجل المحاولة والنجاح ونتيجة الإعادة ذرياً. تغير محتوى المفتاح
  أو النسخة القديمة يعيد 409. تشمل النتيجة الدرجة والإجمالي والنجاح والتغذية
  الراجعة والإنجاز و`unlockedHref` المتاح إن وُجد. لا تكشف الإجابات والشروح إلا
  بعد الإرسال وعند تفعيلها. لا تُقبل حقول `passed` أو`unlocked` من العميل.
- يقبل `POST .../read` الحقل `{version}` لدرس متاح بلا اختبار فقط، ولا يتجاوز
  اختباراً أو متطلباً. تعرض الفهارس الإنجاز منفصلاً عن عدد المنشور. يستمر الإنجاز
  عبر التحديث وتبديل اللغة.

## هوية المتصفح والحدود والاحتفاظ

يتطلب `POST /learning/session` Origin مطابقاً و`X-Blog-Request: 1`. يعيد استخدام
الهوية أو يولد 32 بايت عشوائياً في ملف `__Host-learning` الآمن HttpOnly وSameSite=Lax.
تُخزن بصمة SHA-256 والمعرّف الداخلي والأوقات فقط. تعيد الاستجابة CSRF التعلم.
تبقى جلسة المالك منفصلة. لا تنشئ GET أو المعاينة هوية. حفظ التقدم وإرسال الاختبار
تفاعلان صريحان. يُحفظ التقدم في هذا المتصفح دون استرداد حساب أو مزامنة أجهزة.

يعيد `GET /learning/progress` حالة ملف الارتباط الحالي فقط ومفاتيح العنصر/المجموعة
المنجزة والجيل والطريقة. دون ملف يعيد حالة غير فعالة ولا ينشئ شيئاً. يجدد النشاط
صلاحية الخمول. لا تُقبل هوية يحددها العميل. يتطلب `DELETE /learning/progress`
Origin وCSRF التعلم ويحذف الهوية والمحاولات والإنجازات وينهي الملف. تعيد الواجهة
تحميل الصفحة فوراً حتى لا يبقى درس مفتوح بعد الضبط. تتطلب كل كتابات التعلم
Origin/CSRF وتستخدم الردود no-store.

القيم الافتراضية `BLOG_LEARNING_IDLE_DAYS=180` (1–3650) و
`BLOG_LEARNING_MAX_IDENTITIES=10000` (1–1000000). حد الإنشاء 10/دقيقة لكل IP
موثوق. حد المحاولات 10/دقيقة لكل هوية في SQLite و100/دقيقة لكل IP؛ بصمات IP في
ذاكرة محدودة وتنتهي خلال دقيقة. 429 حد مؤقت للإساءة وليس حداً دائماً للتعلم.
تُحفظ آخر 100 نتيجة لكل هوية لمدة أقصاها 30 يوماً. تُضمن الإعادة المطابقة داخل
هذه النافذة؛ بعد التنظيف يمكن احتساب إرسال لا تزال نسخته حالية كمحاولة جديدة.
لا تُحفظ الاختيارات الخام. الإنجاز الدائم مستقل ولا يحذفه تنظيف المحاولات.
يمنع انتهاء الهوية الوصول فوراً ويحذف حذفها كل تقدمها. تمحو إعادة المسار إنجاز
الأجيال السابقة.

يعمل التنظيف الدفعي كل ساعة. ينفّذ `build/blog cleanup-learning` تنظيفاً كاملاً
ببيئة المشغّل. لا تُزرع بيانات تعلم أو اعتمادات. تغطي الاختبارات الإعادة المتزامنة
والنسخ القديمة والترجمة وكل الحدود السابقة وإلغاء النشر والترتيب والجيل، وتقدم
المتصفح بالخادم الحقيقي باللغات الثلاث ومنع الوسائط الخاصة وإعادة الضبط. لا تثبت
محاكيات مفاتيح المالك توافق العتاد الحقيقي؛ يلزم التحقق على الأجهزة المستهدفة.

يجب ألا يتجاوز JSON التغذية الراجعة المفعلة 120000 بايت لترك مساحة ضمن نتيجة الاحتفاظ البالغة 128 KiB.

# التوصيل إلى المدونة وNotion

[English](lesson-delivery.md) · [الناشر](../api/publisher.ar.md)

يستطيع ناشر Go توصيل درس واحد إلى مسودة المدونة وصفحة مستقلة في Notion.
يحفظ نتيجة كل وجهة مستقلة، ولا يكرر الوجهة الناجحة بسبب فشل الأخرى.
لا توجد مزامنة ثنائية للتعديلات أو الاختبارات أو تقدم التعلم.

```sh
build/publisher deliver --input delivery.json --state-dir /var/lib/lesson-runner
```

مرر `BLOG_URL` و`BLOG_PUBLISHER_TOKEN` و`NOTION_API_KEY` عبر بيئة المشغل الخاصة.
يمكن أن يحدد `BLOG_PUBLISHER_CA` ملف CA موثوقاً. يحتاج تكامل Notion وصولاً
للصفحة الأم المضبوطة؛ اتصال Notion بالمحادثة لا يمنح العملية اعتماد REST.

يحتوي البيان `key` و`locale` و`source_revision` و`notion_parent` و`auto_publish`
(ابدأ بـfalse) و`draft` بصيغة DraftInput مع Markdown. استخدم مفاتيح ومراجعات
ثابتة ومجموعة وموضعاً موجودين. تبقى الترجمات مسودات. يتطلب النشر الآلي باللغة
الأصلية مجموعة مضبوطة صراحة ورمزاً مناسباً؛ لا يراجع تقييماً أو ترجمة ولا يفعّل البوابات.

احفظ مجلد الحالة خاصاً واحتياطياً وخارج Git والإصدارات. يسجل الدفتر المعرّفات
والإصدارات والبصمات والنتائج لا الأسرار أو أجسام الدروس. يمنع قفل حصري لكل مفتاح
تداخل العمال ويبقى بعد الانهيار. تحقق من توقف العامل وافحص الوجهتين قبل إزالة قفل قديم.

بعد الانقطاع أعد البيان نفسه. يرفض المشغل تغيير المصدر أو الوجهة أو البصمة
بدلاً من الكتابة فوق تعديل مستقل. تستخدم المدونة مفاتيح إعادة ثابتة.
تستخدم صفحات Notion لاحقة `[key/locale]` وعلامة مراجعة المصدر وبصمته؛ تفحص
المصالحة أبناء الصفحة مع التصفح. توقف المطابقات المتعددة أو المختلفة التوصيل.
بعد إنشاء غير مؤكد لا يسمح إلا بالمصالحة؛ غياب المطابقة لا يثبت فشل الإنشاء.
تُرفض الحمولة الأكبر من 500000 بايت JSON مشفرة.

اختبر توصيلاً فعلياً للوجهتين وفشل إحداهما وإعادة بلا تكرار من المشغل الحقيقي
قبل تفعيل الجدول. راجع [التوليد المجدول](remote-publishing.md)
و[فحوص الإصدار](../release-readiness.ar.md).

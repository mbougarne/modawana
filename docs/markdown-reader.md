# Shared Markdown reader

[العربية](markdown-reader.ar.md) · [Documentation](README.md)

The shared reader is `frontend/src/features/markdown/MarkdownReader.tsx` for public readers and owner previews. The authenticated preview is `/{locale}/admin/preview/{key}/{contentLocale}` and uses that same component with the exact content locale. Owner preview does not grant public access or create learning progress.

The renderer supports GFM tables/lists, fenced code with copy feedback, math using KaTeX MathML, and optional author-written takeaways. Takeaways pass through the same pipeline; they are never generated by the app. Raw HTML, MDX, scripts and iframe embeds are disabled. Math trust is false and expansion/size is bounded. Markdown is capped at 1 MiB. Code/math stay LTR in Arabic; tables scroll within a keyboard-focusable region. Reader width and media scale use shared design rules.

Images must match a 32-character media ID in the supplied authorized manifest; their URL is reconstructed as `/media/{id}`. Remote/unlisted images are not fetched. A standalone link to manifest video renders controls, optional authorized image poster, authorized VTT captions, caption and transcript disclosure. PDFs use safe download links. Missing/failed media shows localized feedback. The server rechecks access on every media request; a manifest is not an authorization bypass. Links reject controls, credential-bearing URLs and unsafe schemes; HTML is never an escape hatch.

`frontend/tests/markdown.test.cjs` covers malicious input, URL schemes, all locales, code/math/GFM/takeaways and controlled media. `scripts/smoke-configuration.mjs`, invoked by `scripts/smoke-auth.mjs`, verifies real Go-served previews, CSP, MathML, tables, video tracks and private-route/media denial. Public article/doc routes reuse this renderer; do not add a second Markdown pipeline.

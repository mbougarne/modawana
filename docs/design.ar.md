# التصميم والواجهة المشتركة

[English](design.md) · [التوثيق](README.ar.md)

تستخدم الواجهة ترويسة شخصية وقوائم كتابة موجزة ومحتوى سهل القراءة ومساحة تحرير
خاصة. تأتي الهوية من الإعدادات المحفوظة لا من اسم ثابت. حافظ على تحكم موحد للشعار
والتنقل؛ صورة الملف دور منفصل. تدعم التخطيطات العربية RTL والإنجليزية والفرنسية والمظهرين.

## تنظيم المصدر

يمثل `ui/src` مصدر التطبيق المشترك عبر `@ui` وليس تطبيقاً مستقلاً. يضم المكونات
والخطوط والنماذج والمزودات والنصوص. يضم `design-system/` ملف الرموز JSON ومولده
وأنماط المكونات. هذه ملفات مطلوبة لإعادة البناء وتبقى متتبعة. توثيق التصميم هنا.

| المصدر | الاستخدام |
| --- | --- |
| `design-system/tokens.json` | الألوان والطباعة والمسافات والزوايا وعائلات الخطوط |
| `ui/src/styles/index.css` | مدخل الأنماط المشتركة |
| `ui/src/theme` | ThemeProvider وBrandStyle المتوافق مع CSP |
| `ui/src/i18n` | I18nProvider والنصوص ذات الأنواع والجمع والبدائل المضبوطة |
| `ui/src/fonts` | خطوط WOFF2 محلية وتراخيص OFL الأصلية |
| `ui/src/components`, `ui/src/editor` | مكونات القراءة والتحرير والنماذج |

عدّل الرموز في JSON ثم أعد التوليد من جذر المستودع:

```sh
node design-system/scripts/build-tokens.mjs
node ui/scripts/build-tokens.mjs
node scripts/build-label-registry.mjs
node scripts/build-palette-vectors.mjs
```

يلزم أمر النصوص بعد تغيير الافتراضيات، ومتجهات الألوان بعد تغيير خوارزمية اللوحة.
يتحقق `--check` من الملفات المولدة. أبق `design-system/components.css`
و`ui/src/styles/components.css` متطابقين.

## الألوان والطباعة

استخدم متغيرات CSS الدلالية: `paper` و`surface` و`ink` و`ink-muted` و`majorelle`
و`sun` و`rose`. اللون الأساسي الافتراضي أزرق ماجوريل والثانوي أصفر؛ تشتق إعدادات
المالك درجات ملائمة للمظهرين من لونين. استخدم الخوارزمية المشتركة لا تجاوزات
عشوائية. يجب أن تحفظ أنماط الهوية nonce الاستجابة الذي تتطلبه سياسة أمان المحتوى.

Bricolage Grotesque للعناوين وIBM Plex Sans للنص وIBM Plex Mono للكود والبيانات
وIBM Plex Sans Arabic للعربية. احفظ إشعارات الخطوط. اجعل عرض القراءة محدوداً
وتباين النص 4.5:1 على الأقل والتركيز مرئياً وأهداف اللمس 44px، وادعم تقليل الحركة.

## اللغات والتفاعل

تستخدم كل تسمية `t()` مع EN/AR/FR. استخدم CSS منطقياً و`lang`/`dir` للصفحة
واعزل الكود والمعرّفات باتجاه LTR. لا تضف تباعد أحرف للعربية. يسمح الملف والنصوص
ببدائل موثقة؛ تتطلب المقالات والدروس والوثائق والاختبارات توفر ترجمة صريحاً.

اربط التسميات والأخطاء والمساعدة بالحقول. أظهر حالات الحفظ والفشل والتعارض
والفراغ والتحميل. يوفر المحرر الكتابة والمعاينة والوسائط والاختبار والتفاصيل.
افصل الحالة المحفوظة عن المنشورة.

لا تستقبل الدروس المقفلة إلا ملخصاً عاماً. لا تصحح مكونات الاختبار محلياً ولا
تستقبل مفاتيح الإجابة في بيانات القارئ. راجع [عقود الواجهة](ui-contracts.ar.md)
و[Markdown](markdown-reader.ar.md) و[API التعلم](api/learning.ar.md).

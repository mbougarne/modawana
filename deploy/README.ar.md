# إعدادات النشر (Deployment)

[English](README.md)

أمثلة وتكوينات نموذجية قابلة لإعادة الاستخدام لكل من Docker وCompose وCaddy وsystemd. اتبع [دليل النشر](../docs/deployment.ar.md)، ووثيقة [النسخ الاحتياطي والاستعادة](../docs/operations/recovery.md)، ودليل [مشغل نشر الدروس](../docs/integrations/remote-publishing.md) الاختياري.
احرص دائماً على إبقاء أسرار التثبيت والبيانات التشغيلية الحية خارج هذا المجلد.

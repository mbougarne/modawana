# مخطط SQLite والترحيلات

[English](README.md) · [الخادم](../README.ar.md) · [الإعدادات](../../docs/api/README.ar.md)

تحفظ SQLite البيانات الوصفية والمراجعات والمصادقة والإعدادات والمجموعات والاختبارات وتقدم المتصفح والناشر وOAuth. الترحيلات مرتبة وذات بصمات. تبدأ القاعدة دون مالك أو اعتمادات أو ملف أو محتوى أو وسائط.

## الملفات والاتصالات والمعاملات

يستخدم Go مكتبة database/sql مع modernc.org/sqlite v1.61.0 وlibc v1.79.0 المطابقة، مثبتتين في go.mod/go.sum. التشغيل Go خالص دون Node أو خادم قاعدة مستقل. يحتوي BLOG_DATA_ROOT على blog.sqlite وملفات WAL/SHM. يجب أن يكون الجذر المحلول خارج الكود والإصدارات، خاصاً (0700) ومملوكاً لحساب الخدمة؛ وتكون القاعدة والملفات الجانبية الموجودة ملفات عادية خاصة (0600). تُنشأ المجلدات الناقصة بصلاحيات خاصة وتُرفض روابط ملفات القاعدة الرمزية. يتحكم المشغّل الموثوق بالمجلد؛ لا تمنح غيره حق الكتابة في أسلافه.

يطبق كل اتصال فعلي foreign_keys=1 وbusy_timeout=5000 ميلي ثانية وjournal_mode=WAL وsynchronous=FULL وtrusted_schema=0. يحد التجمع بأربعة اتصالات. تبدأ المعاملات IMMEDIATE لتسلسل الكتّاب؛ أبق الكتابة قصيرة ولا تحتجز معاملة أثناء استقبال رفع أو عرض Markdown أو طلب شبكة. يحدّث BumpVersion جداول مسموحة من الكود بعداد متوقع داخل معاملة تغيير المحتوى/الإعداد نفسها. تعني صفر صفوف ErrVersionConflict؛ لا ينجح كاتبان بالنسخة المتوقعة نفسها. تفحص الجاهزية SQLite بمهلة ثانية واحدة، ومهلة ترحيل بدء التشغيل 30 ثانية.

يستخدم NewID المصدر crypto/rand ويولّد معرّفات مبهمة من 128 بت ممثلة بست عشري صغير. تستخدم الأوقات UTC بدقة ميلي ثانية ثابتة (`2006-01-02T15:04:05.000Z`) وافتراضات SQL هي UTC. ترفض القيود الإزاحات المحلية والأوقات المعطوبة. يولد Go معرّفات السجلات الجديدة لا الروابط أو أسماء الملفات أو بيانات الاستيراد.

لا توجد أعمدة لأجسام Markdown أو بايتات الرفع. JSON الإعداد محدود للهوية والملف والنصوص؛ تبقى أجسام About والمقالات والدروس والوثائق ملفات Markdown. تفرض الخدمات تحقق المخطط ومراجعة الترجمة والصلاحيات والتحقق الفعلي من MIME وحصر الملفات. لا تثبت المفاتيح الأجنبية وجود الملف ولا تمنح وصولاً عاماً. تُكتب الملفات الثابتة قبل اعتماد البيانات.

تُدرج النسخة اللغوية الأولى ومراجعتها في معاملة واحدة: توليد المعرّفين، ثم النسخة مع مؤشر المسودة، ثم المراجعة والاعتماد. تؤجل مفاتيح الملكية الدائرية إلى الاعتماد. يجب أن يسمي النشر المراجعة الدقيقة ويتحقق من المراجعة وقواعد الوصول بخدمة المحتوى. يبقى تحقق التطبيق مطلوباً حتى مع قيد SQL مطابق. تشترك خطط المسار وروابط الاختبارات والتصحيح الخاص وهويات المتصفح والمحاولات العامة في قيود المعاملات. تمنع الخطط المفقودة وسياسات الشروط غير المدعومة أجسام الدروس ووسائطها.

## إجراء الترحيل والنسخ الاحتياطي

يضمّن الثنائي SQL مرقماً بدءاً من 0001_core.sql. يتحقق بدء التشغيل من تتابع الأرقام وأسماء وبصمات SHA-256 لكل ترحيل مطبق ثم يطبق SQL المعلق وسجلّه في معاملة واحدة. يرفض جداول موجودة دون إصدارات أو تاريخاً معدلاً أو فجوات أو مخططاً أحدث من فهم الثنائي أو فساد المفاتيح الأجنبية. يعيد فشل SQL الترحيل وتغييرات سجلّه. لا تعدل ترحيلاً مطبقاً؛ أضف معرّف الترحيل التسلسلي التالي غير المستخدم.

قبل بدء ثنائي أحدث على بيانات موجودة:

1. أوقف كل التطبيقات والكتّاب وتأكد من خروجهم، واحتفظ بالثنائي وبناء الواجهة السابقين وإعداد المشغّل الخاص.
2. انسخ مجلد البيانات **كاملاً** مع بقاء الكتابة متوقفة. ضم القاعدة وWAL/SHM وكل Markdown والملفات المرفوعة، لا blog.sqlite وحدها. ضع النسخة خارج مجلد البيانات الحي واحمِ صلاحياتها.
3. تحقق من النسخة واحتفظ بها حتى التحقق من الإصدار الجديد. يفترض المثال التالي على Linux أن BLOG_DATA_ROOT هو الجذر المحلول الفعلي وأن كل الكتّاب متوقفون:

```sh
umask 077
backup="${BLOG_DATA_ROOT}.backup-$(date -u +%Y%m%dT%H%M%SZ)"
cp -a -- "$BLOG_DATA_ROOT" "$backup"
diff -qr -- "$BLOG_DATA_ROOT" "$backup"
```

4. ابدأ الثنائي الجديد بالبيئة الموثقة. يخرج فشل الترحيل قبل بدء HTTP. افحص /readyz واختبارات الإصدار المعنية. للنسخ المنسق أثناء التشغيل والاستعادة الآمنة للاعتمادات اتبع [دليل الاسترداد](../../docs/operations/recovery.md). يحتاج إجراء النسخ هنا توقف الكتابة.

لا توجد ترحيلات رجوع. لا تشغّل ثنائياً أقدم على قاعدة مرقاة ولا تحذف صفوف الترحيل لإجبار البدء ولا تعطل المفاتيح الأجنبية. استعد نسخة كاملة وثنائياً وبناءً وإعداداً متطابقين إلى مجلد خاص منفصل أثناء التوقف، وتحقق قبل تبديل المسار الحي. إذا قبل الإصدار الجديد كتابات، فالرجوع لنسخة أقدم يفقدها؛ خطط لإصلاح أمامي أو تسوية بيانات صريحة. لا رجوع غير متوافق أو إصلاح هدّام تلقائياً.

## التحقق

من backend/ شغّل `go test ./...` و`go test -race ./...` و`go vet ./...` و`go mod verify`. تغطي اختبارات القاعدة الإنشاء وإعادة الفتح وأربعة اتصالات فعلية والقيود ومؤشرات المالك الخطأ وحماية مراجع الوسائط وتاريخ الإعداد وترتيب المجموعة وكاتبين متزامنين وحدود جلسة الاسترداد وإلحاق/إعادة/بصمة/فجوة/مخطط أحدث/تراجع الترحيل والملفات غير الآمنة. محتوى الاختبار في مجلدات مؤقتة فقط. يبدأ CI الخادم الحقيقي ويعيده على جذر واحد لفحص الجاهزية وبناء المتصفح الإنتاجي. لا تختبر هذه الاختبارات أجهزة المفاتيح أو مراسم الاسترداد.

تضيف الهجرة 0006 مراجعات ترجمة الإعدادات والتدقيق الثابتة وعلامة علنية لكل مرجع وسائط إعدادات محفوظ. تبقى صور الشعار غير المستخدمة والأغلفة المعطلة خاصة بينما تمنع مراجعها التاريخية الحذف.  راجع [عقد الإعدادات](../../docs/api/configuration.ar.md).

يضيف الترحيل 0007 الحقل `revisions.reading_minutes` المحسوب للمراجعات الجديدة. تحتفظ المراجعات التاريخية الثابتة بصفر (غير معروف)؛ يحذف الاستكشاف التقدير للمحتوى غير المعروف أو المقفل. لا تُعدّل ملفات Markdown.  راجع [الصفحات العامة](../../docs/public-pages.ar.md).

تضيف الهجرة 0008 تقييمات ثابتة وروابط محلية اللغة بمراجعات المحتوى ومراجعات تقييم دقيقة وشروط خطط مسودة. تضيف 0009 هويات متصفح محفوظة كبصمات وسجل نتائج محاولات محدوداً، دون محتوى Markdown في قاعدة البيانات. انظر [واجهة التعلم](../../docs/api/learning.ar.md) لحدود الاحتفاظ و`build/blog cleanup-learning`.

تضيف 0010 الإنجاز الدائم المستقل عن المحاولات المحفوظة وتضيف 0011 ملكية وسائط الناشر والسماح الصريح بالمقالات. تُحفظ البيانات الموجودة ولا تُزرع اعتمادات. تبدأ الترحيلات الجديدة من 0012.

## 0012 — تحويل المحتوى الصريح

يحفظ الترحيل الإضافي 0012 العناصر والإصدارات ومؤشرات المراجعات الحالية. يضيف
حارس تحويل للمعاملة وتدقيق النوع ومسارات عامة سابقة. تبقى تحديثات النوع ولغة
المصدر والعضوية المنشورة العادية محظورة. تفصل خدمة تحويل المالك فقط عنصراً غير
مخطط وتغير نوعه بمعاملة واحدة؛ تُحمى أعضاء الخطط الفعالة والمسودات. اتبع إجراء
النسخ والبدء أعلاه.

## 0013 — حذف المجموعة

تضيف علامة حذف محفوظة وتمنع إعادة تفعيل المجموعة المحذوفة أو إضافة محتوى إليها.
تفصل عملية المالك الوثائق وتحول الدروس إلى مقالات غير منشورة مع الاحتفاظ بالخطط
والمراجعات الثابتة. تتطلب إصدار المجموعة الحالي. انسخ البيانات احتياطياً قبل
الترقية؛ تبقى مفاتيح المجموعات المحذوفة محجوزة.

## 0014 — مصادقة MCP عبر OAuth

تضيف عملاء OAuth وطلبات الموافقة والرموز والمنح وبصمات التجديد المستهلكة بحدود
محددة. لا تُزرع اعتمادات أو صلاحيات. ترتبط المنح برموز الناشر المقيدة الحالية
وتُحذف عند حذفها. تمسح الاستعادة جميع سجلات OAuth. خذ نسخة واختبر استعادة معزولة
بالبرنامج القديم قبل فتح هذا المخطط بالنسخة المرشحة، واستخدم اللقطة القديمة
المطابقة للتراجع. راجع [تشغيل OAuth](../../docs/integrations/mcp-oauth.md).

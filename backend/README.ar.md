# الواجهة الخلفية (Backend)

[English](README.md) · [المشروع](../README.ar.md)

تتضمن وحدة Go خادم التطبيق الرئيسي (`cmd/blog`) وأداة الناشر المحددة الصلاحيات (`cmd/publisher`). وتتولى الحزم الداخلية تنفيذ وظائف المصادقة، وإدارة المحتوى والوسائط، والإعدادات، ومسارات التعلّم، والتخزين، ونقل البيانات، والنسخ الاحتياطي والاستعادة. يبدأ التطبيق نظيفاً تماماً دون بذر مسبق لأي مالك أو بيانات اعتماد أو محتوى افتراضي.

من هذا المجلد:

```sh
go test ./...
go test -race ./...
go vet ./...
go mod verify
```

ومن المجلد الجذري للمستودع، استخدم الأمر `node scripts/project.mjs build` لبناء كلا البرنامجين التنفيذيين مع أصول الواجهة الأمامية. يتولى خادم Go تقديم أصول الإنتاج ذاتياً دون الحاجة إلى تشغيل Node.js. راجع وثائق [البنية المعمارية](../docs/architecture.ar.md)، و[واجهات البرمجة والإعدادات](../docs/api/README.ar.md)، و[مخطط الترحيلات](migrations/README.ar.md)، و[دليل النشر](../docs/deployment.ar.md).
